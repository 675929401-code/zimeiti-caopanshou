# 视频生成终态计数与媒体访问票据验收报告

日期：2026-08-16

## 1. 本轮边界

本轮只修复视频任务的提交计数、终态计数、播放、下载和历史恢复链路。

- 未修改高能、电影叙事、抒情情感三张故事版导演卡片或提示词。
- 未把自由画布接到三张故事版导演卡片或其 JSON 协议。
- 未修改主题、工具箱、分镜工作台布局和模型渠道配置。
- 未调用任何付费生图或视频任务。

## 2. 已修复问题

### 2.1 视频计数与终态竞争

1. 异步任务提交不再重复增加 request_count。
2. 提交成功不再提前把渠道记为健康成功。
3. 状态轮询和 SSE 同时发现终态时，先争抢同一终态锁，只允许一次成功或失败结算。
4. 成功终态会清理旧错误，不再出现“任务成功但模型仍显示上次错误”。
5. 旧 `/api/video/poll` 改为委托统一状态接口，不再拥有第二套持久化、统计和扣费逻辑。
6. 过期僵尸任务也经过统一终态结算，不再永久占用处理中状态。

### 2.2 登录令牌泄露

旧链路会把长期登录 token 拼到播放、缩略图和下载 URL。现改为 15 分钟短期媒体票据：

- 票据绑定用户、任务、用途和到期时间。
- playback 票据不能下载，download 票据不能播放。
- 票据不能跨任务复用，篡改立即失效。
- 主登录 token 不再出现在视频媒体 URL、DOM、历史记录或浏览器下载地址中。

### 2.3 下载代理与任务碰撞

1. 下载代理不再接受任意外部 URL，只能接收平台真实任务 ID。
2. 查询优先按本地任务主键定位，再兼容旧 external_task_id，避免两个 ID 碰撞后下载错用户视频。
3. 只允许任务所有者或管理员访问已完成任务。
4. 分镜工作台下载失败会显示可见错误，不再静默失败。

### 2.4 历史记录与存储地址

1. 历史接口不再向用户返回 storageUrl。
2. 已完成任务只返回可播放的短期签名地址。
3. 播放票据过期时，视频页和分镜工作台会通过 access-ticket 接口刷新。
4. 内部存储路径、供应商地址、渠道密钥和长期令牌仍只在服务端使用。
