# 发布插件安装教程

> 发布工作台 · 浏览器插件
> 适用于插件 v2.1.0 · 更新于 2026-11-11

发布工作台使用浏览器插件复用当前浏览器中的平台登录态，把作品发布到小红书、微信视频号和抖音。本站不会要求填写平台密码，也不需要把 Cookie 交给网页。

## 教程概览

这份教程覆盖从下载安装、仅授权、配置本站域名，到回到发布工作台检测并连接账号的完整流程。只需要安装一次，以后更新插件时按本页步骤替换旧版即可。

**只从本页下载。** 不要使用聊天群、网盘或陌生链接里的修改版插件。安装前可核对 SHA-256。

## 准备工作

- 一台电脑，使用 Chrome 或 Edge 浏览器；手机浏览器不能安装扩展。
- 同一个浏览器里已经登录要发布的平台账号，例如抖音、小红书或视频号。
- 当前网站地址是 `https://zyuani8.com`；本地预览通常是 `http://127.0.0.1:5000`。
- 如果浏览器开了“下载前询问保存位置”，下载时会先弹出系统保存窗口；否则文件会进入默认下载目录。

## 第一步：安装插件

1. **下载安装包。** 点击本页的“下载插件”按钮，保存 `aitoearn-extension-v2.1.0.crx`。
2. **打开扩展管理页。** Chrome 地址栏输入 `chrome://extensions`；Edge 输入 `edge://extensions`。
3. **开启开发者模式。** 打开扩展页右上角的“开发者模式”开关。
4. **拖入 CRX 文件。** 把下载的 `.crx` 文件拖到扩展页面中间，按浏览器提示确认安装。不要直接双击文件。
5. **确认插件已启用。** 在扩展列表中看到 AiToEarn 插件，并确认开关为开启状态。

Chrome 可能提示“无法从该网站添加扩展”。这是非商店 CRX 的常规限制，请确认已开启开发者模式后，用拖入方式安装。

## 第二步：选择“仅授权”

打开插件侧栏或选项页，点击 **Authorize Only（仅授权）**。这个模式不要求登录 AiToEarn 网页账号，但仍然允许本站调用插件的发布能力。

- 不要选择需要登录 AiToEarn 账号的模式。
- 不要授予与本站无关的网站来源。
- 授权后刷新发布中心或本教程页，让插件重新注入页面。

仅授权只影响插件登录方式；你仍然需要在本站登录自己的账号，并在同一浏览器登录目标平台。

## 第三步：配置本站域名

在插件的“允许注入的域名”中填写发布工作台的来源。正式环境填写：

```text
https://zyuani8.com/
```

本地预览填写：

```text
http://127.0.0.1:5000/
```

每行一个地址，只填写你信任的站点。这里不是抖音、小红书或视频号的网址。点击 **Confirm and authorize（确认并授权）**，然后刷新本站。

## 第四步：连接平台账号

1. 回到发布工作台的“平台账号”页面。
2. 页面检测到插件后，点击目标平台的“连接账号”。
3. 如果账号已在同一浏览器登录，插件会读取账号摘要；按提示确认要发布的账号。
4. 如果页面提示“未检测到插件”，先回到本页重新安装，再点“重新检测”。

没有安装插件时，平台账号页会显示“未检测到浏览器发布插件”，连接浏览器类平台会直接带你回到本教程，不会让你在缺少插件时继续授权。

官方 API 平台不需要浏览器插件，例如快手当前走官方授权/API 通道；这类平台的连接方式与浏览器插件不同，请以平台卡片上的说明为准。

## 常见问题

### 下载后找不到文件

打开浏览器下载记录，查看文件保存位置。Windows Chrome/Edge 默认通常在用户目录的 `Downloads`；也可以在浏览器设置中开启“下载前询问保存位置”。

### 浏览器不允许安装 CRX

确认扩展页已开启“开发者模式”，并且是拖入扩展页面而不是双击文件。仍被拦截时，换用 Chrome/Edge 最新版，或先移除旧版插件再安装。

### 安装后仍提示未检测到插件

刷新发布工作台；确认插件已启用；在本页重新下载最新版。仍不行时重启浏览器，或在扩展页移除旧版后重新安装。

### 如何更新插件

回到本页下载最新版，在扩展页移除旧版后重新安装，再回平台账号页点“重新检测”。不要同时保留多个旧版本。
