## 口径

- 本矩阵按“页面 → API → 权威数据 → 权限 → 资金 → 恢复/历史 → 证据”验收。
- 页面能打开、HTTP 200、静态检查或旧构建截图不能单独关闭功能链。
- 生成、充值、退款、删除、发布和其他写操作默认阻断；真实付费、生产写入和迁移应用必须另行授权。
- 本批前台共 54 个非排除路由模式，R728 实际展开为 108 个 URL，其中包括 37 个动态工具别名和 19 个帮助文章 slug；后台共 14 个一级模块、27 个 tab、7 个指挥中心目标视图。

## 资金与支付强制不变量

1. 创建订单必须先耐久 claim，再调用渠道；同一会员、同一意图只能有一个商户订单号。
2. 回调只信服务端验签、精确金额、商户订单号、渠道交易号和服务端终态；浏览器 return URL 不能到账。
3. `payment_orders`、钱包 operation、不可变账本和到账状态必须同事务幂等提交。
4. 预扣、确认、结算、释放和退款都必须 exactly-once；未知渠道结果进入对账，不自动重放。
5. 无供应商证据的历史异常只能保持 unresolved/reconciliation_required，不能补造凭证或自动改余额。
