## 工具箱改造

### 共同骨架

- 智能分段、文案提取、视频提取、文字排版都采用全宽输入区在上、稳定结果区在下。
- 空态、加载态、成功态和失败态复用结果容器，避免左右空框、尺寸跳动和单卡铺满一屏。
- 桌面、平板和 390px 手机均保持自然纵向流；四个主 Tab 在手机端完整可见。
- 晶层表面、细亮边框、hover/focus/active 状态均由 `/tools` 页面级变量控制，没有修改全局主题文件。

### 文案提取

- “一键粘贴”直接调用 `navigator.clipboard.readText()` 并填入现有输入状态。
- “清空”会清理输入、旧结果和提示，但不修改服务端历史。
- 主按钮继续调用原 `handleExtract`，没有改变 API 语义或绕过登录。
- 失败态提供重试，成功态提供重新提取；既有复制、下载/保存和历史能力保留。
