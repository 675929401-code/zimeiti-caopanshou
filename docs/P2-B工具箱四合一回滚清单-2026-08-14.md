# P2-B 工具箱四合一回滚清单

日期：2026-08-14

## 本轮边界

本轮只收拢顶部/侧栏工具入口，并将智能分段、文案提取、视频提取、文字排版整合到 `/tools`。未修改 `layout.tsx`、`globals.css`、全局主题文件、帮助中心、分镜工作台、生成/计费/安全/智能体协议。

## 可独立回滚单元

### 1. 工具箱页面

- 新增：`src/app/tools/page.tsx`
- 新增：`src/app/tools/tools.module.css`
- 新增：`src/components/toolbox-context.tsx`
- 恢复方式：删除以上文件即可移除 `/tools` 页面；旧 `/segmenter`、`/extract`、`/formatter` 路由仍可独立使用。

### 2. 单一导航入口

- 共享文件：`src/components/toolbox-menu.tsx`
- 共享文件：`src/components/app-sidebar.tsx`
- 共享文件：`src/components/agent-marketplace.tsx`
- 恢复方式：移除 `ToolboxMenu` 引用、`TOOLBOX_SHORTCUT` 和 `collapseToolNav`/旧标签归一化逻辑，可恢复旧的分散入口。此单元不依赖工具页面视觉 CSS。

### 3. 既有工具嵌入模式

- 业务页面：`src/app/segmenter/page.tsx`
- 业务页面：`src/app/extract/page.tsx`
- 业务页面：`src/app/formatter/page.tsx`
- 恢复方式：移除 `useToolboxHost`、`embedded` 条件分支和 `toolbox-*` 辅助类，即可恢复原页面；原 API、历史 key、提交函数和独立路由未改。

### 4. 验收脚本

- 新增：`scripts/verify-toolbox-ui.ts`
- 恢复方式：删除脚本即可，不影响运行时。

## 后续主题接入注意

后续“深空晶层”主题只需提供现有变量：`--background`、`--foreground`、`--card`、`--secondary`、`--border`、`--primary`、`--muted-foreground`、`--ui-line`、`--ui-surface`。不要覆盖 `toolbox-two-column` 的布局属性，即可在不改功能的情况下替换视觉层。
