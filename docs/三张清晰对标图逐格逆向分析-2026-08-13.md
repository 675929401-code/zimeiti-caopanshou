# 三张清晰对标图逐格逆向分析

> 证据：用户提供的三张原始清晰故事板图  
> 目标：分离画面提示、画内知识包装与逐格视频指令，反推可复用的故事版智能体方法  
> 边界：这是基于可见成品的工程逆向，不声称取得对方私有系统提示词原文

## 一、总判断

对标不是“普通皮克斯暖色家庭图 + 几个贴纸”，而是三层视觉系统叠加：

1. **可信的3D动画底片**：圆润造型、精细毛发与布料、柔和但有方向的电影光、强轮廓、浅景深和高质量材质。
2. **动画与漫画动作层**：大眼、张嘴、肢体拉伸、弹性变形、运动残影、速度线、冲击云、爆炸火花、旋风和夸张透视。
3. **知识包装层**：维生素卡片、发光骨头、体重秤、医院牌、圆形知识窗、警告三角、中文结论牌。这些是剧情中的巨大道具或图形揭示，不是小贴纸。

因此，准确名称应为：

`高饱和商业级3D动画喜剧 + 漫画式2D动作特效 + 巨型知识道具揭示 + 高能短视频分镜`

只写“皮克斯风格”不足以得到这种效果。

## 二、三张图共同的角色与造型

### 女主人

- 年轻女性，超大眼睛、小鼻口、圆润面颊，头身比明显动画化。
- 深棕高马尾，黄色连帽卫衣、蓝色牛仔裤、白色运动鞋。
- 表情并非克制：眉毛高挑或压低，瞳孔方向明确，嘴巴大幅张开，手指充分张开。
- 动作始终有明确弧线：飞扑、后仰、伸手阻挡、举牌、端盆、冲入画面。

### 柯基

- 三色短腿柯基，黑色背毛、暖橙脸颊与耳朵、白色口鼻和胸口。
- 头略大、眼睛极大、短腿、蓬松尾巴，轮廓在缩略图中一眼可认。
- 保持犬类四足体态，但允许卡通弹性：腿部弯折、身体拉伸、毛发旋涡和夸张急刹。
- 表情系统使用眼白、瞳孔、眉眼、耳朵和张口幅度，不依赖说明文字。

## 三、画面质感与色彩

### 不是单一“暖色皮克斯”

对标的综合色彩具有以下结构：

- 主体基础色：暖橙、蜂蜜黄、奶油白、柯基黑色背毛。
- 正向知识揭示：高亮金黄、橙黄、白色放射光。
- 危险与冲突：警告红、橙红火花、暗褐或近黑背景。
- 空间对比：天空青蓝、医院蓝白、草地高饱和绿色。
- 阴影不浑浊：暗部常偏冷或保持中性色，亮部偏金黄，形成明显冷暖分离。

色彩不是全片统一棕黄，而是每格按“正常 → 触发 → 爆发 → 揭示”改变功能色和对比度。

### 灯光与材质

- 强暖侧逆光、毛发轮廓光、眼睛高光和局部辉光。
- 关键知识道具自发光，并向人物和柯基投射暖色反光。
- 灰尘、毛絮、火花和空气粒子接受场景光，形成空间层次。
- 毛发、布料和地面材质可信，但物理规律可为喜剧表演让步。

官方 RenderMan 资料说明，Pixar 式风格化涉及造型轮廓、材质、灯光、阴影和可导演的特效，并会为了故事主动打破物理准确性；这与对标图“可信底片 + 非真实漫画动作”的组合吻合。

## 五、下方英文到底是什么

下方英文不是普通图片说明，也不是口播字幕。它是每格对应的**压缩版图生视频执行提示词**，固定包含：

`Frame编号 + 高强度运镜 + 主体持续动作 + 物理/漫画特效运动 + 情绪或知识揭示结果`

常见运镜词：

- `Rapid tracking shot`：快速跟拍
- `Fast lateral pan`：快速横摇
- `Explosive push-in`：爆炸式推近
- `Whip pan`：甩镜
- `Smash zoom`：猛推急变焦
- `Rapid tilt up`：快速上摇

因此对标链路实际拥有两个输出层：

1. **整张故事板文生图Prompt**：负责角色、每格动作峰值、特效、知识道具、综合色彩和故事板排版。
2. **逐格图生视频Prompt**：每格一条英文短指令，同时显示在图片下方并在后续视频Prompt中展开为时间动作。

画内中文和 Vitamin A/B/D 则属于第一个生图层，是画面中的剧情知识道具。

## 六、可复用的对标方法论

### 1. 每段先选择一个“视觉母题”

不是给每格随机加贴纸，而是让整段围绕一个能不断升级的视觉母题：

- 缺乏维生素D：腿部不稳 → 弯曲 → 电流 → 乱吃异物 → 警告揭示。
- 缺乏维生素A：眼睛异常 → 放大检查 → 维生素卡 → 狂吃不胖 → 体重证据。
- 缺乏维生素B：医院钩子 → 掉毛旋风 → 毛团扑脸 → 维生素盾牌揭示。

### 2. 四至五格必须包含功能差异

`异常钩子 → 追逐/检查 → 具象症状 → 原因或证据 → 巨型结论揭示`

四格可合并其中一项。每格不是同一场景换角度，而是升级一种新事件或新视觉机制。

### 3. 每格采用“角色表演 + 环境破坏 + 知识包装”三选二

- 角色表演：大眼、张口、耳尾、重心、弹性变形。
- 环境破坏：尘土、食物、毛团、碎屑、火花、草屑、气流。
- 知识包装：发光卡片、盾牌、体重秤、圆形知识窗、警告牌。

至少两层同时存在，画面才不会像监控截图。

### 4. 每段必须有一个“超大知识揭示物”

知识点不应只写成小图标。把最关键的概念变成占画面约20%至35%的卡片、盾牌、骨头、秤、警示牌或教学窗，并让其发光、遮挡角色、投射反光或改变角色动作。

### 5. 动作特效必须有空间方向

速度线、残影、冲击云、火花、旋风和碎屑都需要明确来源、方向、遮挡、前后景和落点。禁止均匀散布“装饰元素”。

## 七、与本站旧提示词的关键差距

1. 旧版把表演写成“紧张但克制”，对标使用极端可读表情和身体弹性。
2. 旧版限制每格一个小包装，对标常用一个巨型知识道具加一组动作特效。
3. 旧版认为家庭场景不应强烈漫画化，对标恰恰把普通场景推入高能漫画动作。
4. 旧版使用深黑信息条，对标是白色底、黑色居中的完整英文视频指令。
5. 旧版五格仍围绕同一公寓连续动作，对标会为了讲清知识跨场景、进入抽象金色知识空间或医院。
6. 旧版禁止较多画内文字，对标把少量、巨大、可读的中英文概念作为核心剧情资产。
7. 旧版强调电影克制，对标强调商业短视频的第一眼冲击、喜剧恐慌和爆炸式揭示。

## 八、验收标准

- 缩略图中每格动作和情绪均可读。
- 至少一格追逐或物理爆发，至少一格知识道具揭示，至少一格情绪/症状特写。
- 角色表演强度达到大眼、张口、肢体曲线和明确重心变化，不靠说明文字补情绪。
- 每格至少有角色表演、环境反馈、知识包装中的两层。
- 整段拥有统一视觉母题，特效不是随机库套用。
- 高光偏暖金，暗部保持中性或偏冷；功能色清晰且不脏。
- 下方白条包含完整、准确、可执行的英文视频短指令。
- 画内只出现由当前知识点推导出的少量巨大概念文字，不出现无关字幕。
