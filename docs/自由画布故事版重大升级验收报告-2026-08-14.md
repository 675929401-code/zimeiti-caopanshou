# 自由画布故事版重大升级验收报告

日期：2026-08-14

## 结论

本轮已把“故事版导演 + 意图多格”接入自由画布的源头链路。此前并行窗口没有真正改到自由画布，本轮已直接在主项目落地并完成无费用验收。

## 已完成

1. 自由画布制作抽屉新增三种故事版导演选择：
   - 高能夸张
   - 电影叙事
   - 抒情情感

2. 自由画布制作抽屉新增目标视频时长：
   - 10秒：3-4个真实视频镜头
   - 15秒：4-5个真实视频镜头

3. 接入意图多格规则：
   - 4格：2x2故事板
   - 5格：上方2x2 + 底部全宽远景/高潮/结论锚点
   - 格子用于参考图规划，不等于视频必须机械硬切同样次数

4. 源头提示词生成改造：
   - 每段口播先转成可演的微故事
   - 锁定具体角色、宠物、道具、环境和风格
   - 生图提示词输出故事板参考图
   - 视频提示词强调“怎么演”、真实镜头数、运镜节奏和不要按格硬切

5. API 入参打通：
   - `/api/canvas/compile-script` 支持 `storyDirectorMode`
   - `/api/canvas/compile-script` 支持 `targetDurationSeconds`

6. 画布节点映射更新：
   - 参考图节点标题展示“4格/5格故事板参考图”
   - 视频节点标题展示真实镜头数
   - 生成历史与节点数据保留时长、格数、布局、镜头数、节奏模式等字段

7. 修复制作面板崩溃：
   - 某些模型价格字段为空时，原代码 `.toFixed()` 会导致打开制作面板崩溃
   - 已改为价格容错显示，面板不再崩溃

8. 保留批量提交节奏：
   - 图片：每5秒提交1个任务
   - 视频：每8秒提交1个任务
   - 提交后仍可并发等待，不改成串行等完一个再提交下一个
