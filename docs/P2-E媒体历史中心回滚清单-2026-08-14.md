# P2-E 媒体历史中心回滚清单

## 改造边界

本阶段只新增统一媒体历史聚合、浏览器本地媒体缓存、独立页面与一个工具箱入口。未修改分镜工作台、视频生成/轮询、计费、安全或智能体协议。

## 文件与局部恢复

| 模块 | 文件 | 恢复方式 |
| --- | --- | --- |
| 聚合接口 | `src/app/api/media-history/route.ts` | 删除新增目录即可恢复；不影响原视频历史接口 |
| 媒体内容代理 | `src/app/api/media-history/content/route.ts` | 删除新增文件即可恢复 |
| 缓存策略 | `src/lib/media-cache-policy.ts` | 删除新增文件 |
| 浏览器缓存 | `src/lib/media-cache.ts` | 删除新增文件；浏览器中遗留的 `platform-media-cache-v1` 可由页面清理或 DevTools 删除 |
| 历史页面 | `src/app/media-history/page.tsx`、`media-history.module.css` | 删除新增目录 |
| 工具箱入口 | `src/components/app-sidebar.tsx` | 仅移除 `MEDIA_HISTORY_SHORTCUT`、对应去重判断及插入项 |
| 旧历史清理 | `src/app/api/video/history/route.ts` | 恢复原来的 20 天后台删除块（不建议，会删除服务端任务记录） |
| 验证 | `scripts/verify-media-cache.ts`、`scripts/verify-media-history-ui.ts` | 删除新增脚本，并移除 `package.json` 中两个 `verify:media-*` 命令 |

## 数据影响

- 不新增服务端数据表，不迁移计费或任务数据。
- 本地视频副本写入浏览器 Cache API；元数据写入 IndexedDB。
- 本地缓存 key 使用当前用户 ID 的不可逆摘要作为 scope，账户切换后不会列出其他用户缓存。
- 自动清理只删除过期本地副本，不删除 `video_tasks`、会话消息或账务记录。
- “删除服务端记录”是独立确认操作，并由服务端再次校验所有权。

## 局部回滚顺序

1. 先从 `app-sidebar.tsx` 移除媒体历史快捷入口，避免用户进入待回滚页面。
2. 删除 `src/app/media-history` 与 `src/app/api/media-history` 两个新增目录。
3. 删除两个 `src/lib/media-cache*` 文件和两个验证脚本。
4. 清理浏览器 Cache Storage `platform-media-cache-v1-*` 与 IndexedDB `platform-media-cache-v1`；这一步只影响本地副本。
5. 不恢复旧接口的 20 天自动删除块，除非产品再次明确要求删除服务端任务历史。
