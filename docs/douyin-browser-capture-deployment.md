# 抖音公开页面采集助手部署说明

## 目标

让“对标账号拆解师”同时支持两条免费资料入口：

- 服务器直采：用户粘贴抖音官方链接，服务器使用独立 Chromium 尝试读取公开页面。
- 浏览器辅助：服务器受登录或风控限制时，用户在自己的 Chrome 中正常登录抖音，点击扩展读取当前页面已经加载的公开资料。

两条入口最终都进入同一个后台技能 `collect_douyin_public_profile`，统一返回账号快照、作品样本、证据状态、缺失项和使用边界。

## 登录机制

扩展不负责登录，也不保存登录凭证。用户在 Chrome 正常登录抖音后，登录状态由 Chrome 与抖音自行维持。扩展只在用户点击按钮时读取当前标签页已经展示的公开内容。

扩展不申请 `cookies`、`history`、`webRequest`、下载或后台常驻权限，也不读取 `document.cookie`、LocalStorage 或 SessionStorage。

## 网站部署

Docker 运行镜像已经安装 Chromium、NSS、字体和 FFmpeg，并设置：

```bash
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium-browser
```

非 Docker 服务器需要自行安装 Chromium，然后在环境变量中填写实际路径。服务器必须允许访问抖音公网，并预留浏览器运行所需的内存。建议限制并发采集数量，避免短时间高频访问。

## 扩展交付

部署后，扩展安装包位于：

```text
/downloads/douyin-public-capture-extension-v1.0.0.zip
```

用户下载并解压后，在 Chrome 的 `chrome://extensions/` 中打开开发者模式，选择“加载已解压的扩展程序”。正式大规模商用时可再提交 Chrome 扩展商店审核；当前压缩包适合内部使用和小范围学员测试。

## 用户流程

1. 用户在 Chrome 正常登录抖音。
2. 打开对标账号主页并向下滚动，加载需要分析的作品。
3. 点击“抖音公开页面采集助手”。
4. 点击“采集当前已加载内容”。
5. 扩展把 `DY_CAPTURE_V1` 采集包复制到剪贴板。
6. 用户打开“对标账号拆解师”，将采集包粘贴到“抖音链接/浏览器采集包”。
7. 后台校验官方域名、包体大小、字段和作品数量，再交给智能体完成30维拆解。

## 不能承诺的能力

- 不能绕过登录、验证码或平台风控。
- 不能取得任意账号后台的完播率、受众画像或历史涨粉曲线。
- 没有公开字幕时，作品描述不能冒充完整口播文案。
- 页面当前未加载的作品不会出现在采集包中。
- 数据中心 IP 可能被限制，因此必须保留浏览器辅助和用户补充资料两种降级路径。

## 安全验收

- 只允许 `douyin.com` 与 `iesdouyin.com` 官方域名。
- 单个采集包最大40万字符，最多导入30条作品。
- 未定义字段全部丢弃，密码或 Cookie 字段不会进入工具结果。
- 页面文字始终标记为不可信外部资料，不执行其中的指令。
- 工具报告必须说明采集方式、时间、样本数、缺失项和证据状态。
