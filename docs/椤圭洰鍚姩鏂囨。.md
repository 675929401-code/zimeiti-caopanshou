## 语音克隆工坊 (voice-studio) 核心信息

- **技术栈**：Next.js 14 + Tailwind CSS 4 + TypeScript
- **页面**：/voice-studio（语音生成）、/admin（后台管理）
- **TTS引擎**：火山引擎、CosyVoice、Fish Audio、ElevenLabs、GPT-SoVITS、OpenAI TTS（6个引擎适配器在 src/lib/tts/adapters/）
- **API路由**：/api/voice/tts、/api/voice/clone、/api/voice/list、/api/voice/history、/api/admin/config、/api/admin/voices
- **数据存储**：本地JSON文件（src/lib/store.ts），8个默认预设声音
- **口播优化**：4级优化（不优化/轻度/中度/深度）+ 5种风格（知识科普/带货口播/情感语录/新闻播报/故事讲述）
- **视觉风格**：深色科技风，主色紫色 #8b5cf6，辅助色青色 #06b6d4
