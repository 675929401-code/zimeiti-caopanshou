# 自由画布全链路测试与纠错记录

日期：2026-08-10  
页面：`http://127.0.0.1:5000/free-canvas`  
范围：镜头拆分、关键帧生图、图生视频、结果预览、批量下载、耗时诊断。

## 执行原则

- 真实生成过程中只记录问题，不边跑边修改。
- 全部图片与视频结束后统一汇总，再集中优化并复测。
- 当前阶段不测试配音、字幕或合成；视频提示词中的声音仅指环境音与动作音。
- 真实测试要区分任务提交、供应商排队/生成、结果保存、目标时长裁剪和节点总耗时。

## 已定位问题

| 编号 | 严重度 | 问题 | 当前处理 |
|---|---|---|---|
| P-01 | 高 | 原顶部只有一个会变化含义的主按钮，用户无法判断先出图还是先出视频。 | 已改为固定三阶段按钮，并保留“全部生成”。 |
| P-02 | 高 | 原右侧 404px 面板混放模型、方向、帮助、历史、检查、计时和统计，信息密度过高。 | 已改为半屏抽屉和三标签分组。 |
| P-03 | 中 | 原节点等待期只显示“执行中”，无法区分上游排队、模型生成、保存和裁剪。 | 卡片已显示细分阶段，并写入本地诊断记录。 |
| P-04 | 中 | 结果预览和批量下载不在高频位置。 | 节点卡新增预览/下载；顶部新增显眼的批量下载。 |
| P-05 | 中 | 全部节点当前按拓扑顺序串行执行；多镜头总耗时会累加，可能是批量任务显著变慢的重要原因。 | 先保留现状用于真实基线测试；真实记录完成后再决定安全并发数。 |
| P-06 | 中 | 旧画布 UI 自动化脚本仍使用已失效的面板标题与字段名称。 | 已更新选择器，并新增无需付费的生产阶段验收脚本。 |
| P-07 | 中 | 为避免额外消耗，前端把所有不能原生生成 1 至 4 秒的模型直接禁用，导致用户无法主动选择固定长时模型。 | 已增加默认关闭的“生成后自动裁剪”；开启后解锁兼容模型，并明确显示原生时长、目标时长及完整原片计费。 |
| P-08 | 高 | 动漫编排器生成了视觉装饰方案，但最终生图提示词未携带，参考图只能表现主体、场景和光影。 | 已把解析后的具体装饰写入独立“视觉装饰”行，并同步给视频动作方案。 |
| P-09 | 中 | 旧装饰方案含“保持干净 / 不出现文字”等尾句，编译器会丢弃整句并造成相邻镜头机械复用装饰。 | 仅清理否定尾句，保留启动线、接触暖光、声波等正向效果；本镜动作优先于整段口播推理。 |
| P-10 | 中 | 动漫默认轻量包装，难以达到快节奏剧情动画的视觉密度。 | 动漫剧情默认改为“剧情强化（推荐）”；真人剧情仍默认无包装，10秒模式仍保持轻量。 |
| P-11 | 高 | 旧画布仍可绕过新提示词链路直接付费生图，生成无装饰参考图后视频阶段也无法可靠补回。 | 单节点、生图批量、视频批量及全部生成均加入装饰预检；缺少具体元素时要求重新拆镜，视频提示词禁止新增参考图中不存在的装饰。 |
| P-12 | 中 | 装饰虽然能生成，但未约束视觉占比和场景材质时可能过大或呈现为平面贴层。 | 剧情强化限制装饰总面积不超过12%，并要求继承场景光照、透视与立体材质；轻量装饰限制为8%。 |
| P-13 | 高 | 默认自动模式只有文字版角色设定，没有图片身份锚点，独立生图时角色外观仍会跨镜漂移。 | 已记录，待评估“自动生成1张角色锚点后复用于全片”的成本、模型兼容与交互闭环。 |

## 待执行真实测试

状态：等待在已登录主平台的自由画布会话中执行。  
顺序：镜头拆分确认 → 开始生图并等待全部完成 → 逐图抽检 → 开始生成视频并等待全部完成 → 逐条预览 → 批量下载 → 导出诊断记录 → 汇总优化。

真实测试完成前，不把模拟结果当作模型质量结论，也不把供应商生成耗时与平台保存/裁剪耗时混为一谈。

本轮自动化只验证裁剪授权、请求参数、状态流转和交互，不产生真实模型费用；最终画质与真实裁剪耗时仍纳入后续登录会话的付费测试。

本轮装饰链路复测同样只执行镜头拆分和节点审计，没有提交图片或视频生成。现有已生成参考图不会被追溯修改，需要重新执行“镜头拆分”并重新生图后才能看到新增装饰。
