# 故事版导演三卡稳定协议 v6.2

## 升级边界

v6.2 是兼容升级，不精简、不推倒三张导演卡的创作核心。数据库迁移保留现有提示词中以下内容：

- 全片角色、场景和道具资产锁定；
- 口播转故事的方法；
- 按当前语义推导画面包装，而非固定贴纸库；
- 10 种 3D 动画风格执行字典；
- 4 至 5 格故事板画面方法；
- 图生视频的动作、运镜、物理反馈和声音边界；
- 高能夸张、电影叙事、抒情情感三种独立导演策略。

本次只修复固定 10 秒、面板等于切镜、时长字段缺失和机器字段不完整的问题。

## 输入协议

版本继续使用 `storyboard_director_input.v1`，以加法方式兼容旧输出。

| 稳定字段 ID | 类型 | 说明 |
| --- | --- | --- |
| `segmented_script` | string | 已分段口播文案，保留编号、边界、顺序和原字 |
| `animation_style` | string | 10 种 3D 动画风格之一 |
| `aspect_ratio` | `16:9 \| 9:16` | 整张故事板和成片比例 |
| `target_duration_seconds` | `8 \| 10 \| 15` | 默认 10 秒 |
| `special_notes` | string | 角色、产品参考和禁用内容等选填要求 |

旧字段 `storyboard_segmented_copy`、`storyboard_visual_style`、`storyboard_aspect_ratio`、`storyboard_character_setting`、`storyboard_special_requirements` 继续兼容。旧请求没有时长时按 10 秒处理。

后台预设字段使用 `defaultValue="10"`。通用预设解析器和用户端弹窗均保留这个值；没有默认值的旧卡片行为不变。

## 口播估时

1. 去除空格和不发音标点后，按约 6 个有效字/秒估算。
2. 再加 0.3 至 0.8 秒自然停顿。
3. 输出 `estimated_narration_duration`。
4. 未来接入真实 TTS 后，以真实音频时长覆盖估算值。
5. 估算明显超过目标时长时，不压缩为 6 格以上，也不快速碎切；明确建议拆成下一生成单元。

## 面板规则

- 8 秒通常使用 4 格 2×2；只有独立高潮、警示或结论值得宽幅表现时才使用 5 格。
- 10 秒按语义在 4 格和 5 格之间选择。
- 15 秒通常使用 5 格；抒情或低信息密度段落仍可使用 4 格。
- 永远最多 5 格。
- 4 格：`panel_count=4`、`layout=two_by_two`、`panoramic_anchor_role=null`。
- 5 格：`panel_count=5`、`layout=four_plus_panorama`，Prompt 必须包含 `top four panels in a 2x2 grid, bottom Frame 5 full-width panoramic panel`。
- 禁止上 2 下 3 等宽、五张独立图、错序拼贴和为了版式硬凑第五格。

面板是动作阶段和参考素材，不是视频切镜清单。

## 时长与镜头

| 时长 | 高能夸张 | 电影叙事 | 抒情情感 |
| ---: | ---: | ---: | ---: |
| 8 秒 | 2–3 镜 | 2–3 镜 | 1–2 镜 |
| 10 秒 | 3–4 镜 | 2–3 镜 | 1–2 镜 |
| 15 秒 | 4–5 镜 | 3–4 镜 | 2–3 镜 |

只有语义确实需要时才取上限。每个实际镜头必须输出连续的 `shot_time_ranges`，起点为 0，终点覆盖目标时长；`continuity_links` 说明动作、视线、声音或空间如何交给下一镜头。

三种导演不是只换形容词：

- `high_energy`：强动势、预备与爆发、夸张反应、弹性回震、漫画化语义效果；
- `cinematic`：有动机运镜、空间连续、动作匹配、光影和叙事节奏；
- `lyrical`：微表演、呼吸、视线、身体距离和情绪递进。

## 输出协议

每段仍先后输出两个独立、可一键复制的标准 Markdown `text` 代码框：

1. `storyboard_image_prompt`
2. `image_to_video_prompt`

所有段落结束后输出一个 `json` 机器包。平台只按稳定字段 ID 读取，不按标题或代码框顺序猜测。

```json
{
  "schema_version": "storyboard_director_output.v1",
  "artifact_type": "storyboard_director_package",
  "director_mode": "high_energy",
  "input": {
    "schema_version": "storyboard_director_input.v1",
    "segmented_script": "",
    "animation_style": "",
    "aspect_ratio": "16:9",
    "target_duration_seconds": 10,
    "special_notes": ""
  },
  "segments": [
    {
      "segment_id": "segment_001",
      "source_index": 1,
      "narration": "",
      "target_duration_seconds": 10,
      "estimated_narration_duration": 8.7,
      "panel_count": 4,
      "layout": "two_by_two",
      "pacing_mode": "fast",
      "actual_shot_count": 3,
      "shot_time_ranges": [
        {
          "shot_id": "shot_01",
          "start_seconds": 0,
          "end_seconds": 3.2,
          "action_beat": ""
        }
      ],
      "panoramic_anchor_role": null,
      "continuity_links": [
        {
          "from_shot": "shot_01",
          "to_shot": "shot_02",
          "link_type": "sound_bridge",
          "description": ""
        }
      ],
      "character_assets": [],
      "semantic_visualizations": [],
      "storyboard_image_prompt": "",
      "image_to_video_prompt": ""
    }
  ]
}
```

解析器继续兼容旧 `frame_count` 和旧双 `text` 代码框。旧输出缺少时长、时间轴或连续性字段时，按 10 秒生成明确标记为兼容值的 DTO，不重复插入工作台。
