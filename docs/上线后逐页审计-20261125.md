   - 修复：将新 release 的 `public/commerce/` 同步到 `static-commerce`，图片恢复 200。

2. **5 个构建产物缺失素材**

   - `/commerce-video-families/bytedance.svg`、`kling.svg`、`qwen.svg`
   - `/commerce/reference/e160dffc79895d52.jpg`
   - 根因：发布清单 `public-code-track` 未收录这些文件，CI 制品未打包；已手工补到服务器，并把清单/策略补齐（PR #69）。

3. **代码默认图标 404**
   - `/commerce/reference/director-custom.png` 被多处用作兜底图标，但仓库和线上都不存在；已生成并上线。

4. **favicon 404**
   - 已补 `public/favicon.ico` 并上线。

5. **巡检表缺失**
