# 哈尼有话讲：动漫剧情导演逆向研究与画布生产方案

## 0. 结论先行

这不是一份“把十条视频概括成几句话”的内容总结，而是一份用于改造导演智能体和自由画布的工程依据。

当前结论如下：

1. 对标作品的核心不是某个固定画风，而是稳定的导演语法：把口播知识点改造成可演的微剧情，再用身体反馈、道具夸张、环境反馈或完整语义切片把抽象因果变成观众一眼能懂的画面。
2. 对标成片并非“一段口播对应一张参考图和一条 4 秒视频”这么简单。约 474 秒样本出现 482 个场景变化候选，接近每秒一次视觉变化。即使其中包含镜内构图与光效变化，也能确定它依靠高密度剪辑节拍，不是只靠长镜头提示词。
3. 当前画布已经具备文案拆分、角色资产、参考图和图生视频的主干，但缺少四个决定成片质量的环节：镜头导演决策、镜内与镜间节奏规划、候选生成与质检回退、最终剪辑包装。
4. 当前流程可以产出“方向相近的单镜头素材”，不能诚实承诺稳定得到“与对标同等级的完整成片”。若不补齐剪辑与质检层，继续只改视频提示词会遇到上限。
5. 不需要回到依赖段落顺序解析的旧方案。后台仍可把导演提示词放在一个完整输入框中；模型必须输出稳定 JSON 契约，画布只按字段名加载，不按提示词的自然语言顺序猜测。
6. 本报告能逆向的是镜头策略和提示词蓝图，不能取得对方系统中不可见的原始提示词。下文所有“逆向提示词”均是依据成片重建的可执行方案，不冒充原始文本。

## 2. 十条视频逐条逆向

### 2.1 养狗真相：用道具把知识点变成物理事故

**观察**

- 开头用盐瓶与狗的俯拍关系进入问题，随后盐瓶落下，狗身后出现邪恶阴影。
- “调味”“白色蔬菜”“黄瓜”“红薯”“便秘”分别被转成方便面暴食、发光白菜、黄瓜咀嚼特写、烤箱红薯、卫生纸与马桶等具体事件。
- 画面频繁在道具特写、角色反应、食物微距、身体状态和讲师式收尾间切换。

**导演方法推断**

- 每个知识点不是直接画“狗在听解释”，而是先给诱惑物，再让狗执行动作，最后让环境或身体反馈后果。
- 视觉证据按“实物 -> 行为 -> 反馈”排列；当普通动作不够直观时，升级为发光器官或巨大化道具。
- 结尾固定回到角色面向镜头的讲解或关注动作，构成栏目记忆。

**逆向生图蓝图**

`具体犬种与固定外貌 + 单一动作前势 + 单一可触碰道具 + 后果证据 + 近/中景机位 + 可见空间层次 + 统一电影级 3D 动画材质`。

示例：`16:9，短腿白棕杰克罗素梗保持自然四足犬体态，前爪压住餐桌边缘，鼻尖距离一根带水珠的黄瓜仅几厘米，耳朵前倾、眼神兴奋，黄瓜位于前景形成夸张透视，暖色客厅厨房背景虚化，侧逆光勾勒短毛，低机位近景，电影级家庭动画质感，不出现人形躯干和可读文字。`

**逆向视频蓝图**

`狗先快速凑近闻黄瓜，随后张嘴咬住并用前爪稳住，咀嚼两次后眼睛突然亮起星形高光，尾巴加速摇动；镜头从黄瓜微距缓慢拉到狗的面部近景，桌面水珠被动作震动，最后停在满足表情。`

**画布启示**

- 每个镜头必须显示“可见命题”和“证据等级”，否则模型容易写成解释文字。
- 镜头卡应区分主动作、结果反应和后期字幕，不允许把字幕内容塞进生图提示词。

### 2.2 人类食物：用欲望、失控和身体反馈制造喜剧

**观察**

- 金毛从趴睡、看见食物、冲向食物、愤怒护食推进，动作始终围绕食物道具。
- 出现烟团、黄色黏液、狼藉房间、胸腔透视和眼睛放电等高强度包装。
- 近景鼻头、食物飞入、全身反应和体内证据交替出现。

**导演方法推断**

- 先表现“想吃”，再表现“得到后失控”，最后把身体后果可视化。
- 包装效果从剧情动作触发：愤怒触发烟团，刺激触发眼部放电，身体风险触发骨骼或器官透视。
- 情绪不靠形容词完成，而靠耳朵、瞳孔、嘴角、身体重心和环境反馈共同完成。

**逆向提示词关键句式**

- 生图：描述动作发生前最有张力的一帧，例如食物盘刚滑入画面、犬只前爪已经抬起但尚未扑到。
- 视频：第一句直接命令动作，例如“盘子从画面右侧滑入，金毛立刻抬头并扑向桌边”，不先复述角色设定和系统协议。

**画布启示**

- 参考图必须是视频动作的起跑线，不是角色设定说明书。
- 视频节点只接收锁定资产、参考图和动作指令；“必须使用参考图”属于系统参数，不应成为视频正文的主要内容。

### 2.3 狗开口劝阻：把每个禁忌变成一场风险表演

**观察**

- 哈士奇戴眼镜开场，眼镜反射或射出光束；随后出现米饭/面条、胸腔与肠胃透视、雷云。
- 洗护场景使用心形发光区域，鸡蛋被做成瞄准目标，某些禁忌切入绿色骷髅空间。
- 结尾用黄瓜和烧烤/火焰空间形成安全与危险对照。

**导演方法推断**

- 角色不是讲解员，而是亲历者：闻、吃、退缩、发抖、瞪眼、逃离。
- 同一信息点可先在现实空间建立动作，再切到完整语义空间展示严重后果。
- 完整语义切片不是装饰贴纸，而是可被角色进入、受力和反馈的剧情场景。

**规则**

- `visualMode=semantic_cutaway` 时，切片场景可以占据 30%-100% 画面，不受轻量包装比例限制。
- 普通犬必须保持具体犬种和自然四足骨架；眼镜只有文案或前后剧情需要时才允许保留，不能变成默认人物化服装。

### 2.4 水果清单：危险色彩编码与安全奖励闭环

**观察**

- 开头先用眼睛微距和大型红色 3D 标题制造警报。
- 危险水果阶段出现病犬、医院、牛油果、绿色骷髅、粉色诱惑空间、碎裂眼神、黑色毒雾。
- 安全水果阶段回到自然家居，用梨、星星眼、金色光环和“15 岁”心形图层完成正向奖励。

**导演方法推断**

- 不是每个水果都采用相同模板；危险项依次使用临床后果、毒素空间、感官破裂和黑雾等不同证据，避免机械重复。
- 危险统一采用绿黑、红黑和低键光；安全统一采用暖黄、白金和柔和家居光，形成跨镜头色彩语义。
- 大标题、编号、可读文字和关注标识属于后期图层，生成画面只预留构图安全区。

**逆向视频蓝图**

`牛油果切片从高处落在桌面，棕色贵宾犬先兴奋靠近闻嗅，鼻尖刚接近果肉便猛然后缩，耳朵贴后、前爪连续退两步；绿色毒雾从果肉缝隙扩散成骷髅轮廓，厨房暖光被压成冷绿色。镜头先跟随果片下落，再低位推近狗的惊恐面部，最后停在狗与危险果实的距离关系。`

**画布启示**

- 需要项目级“色彩语义表”：危险、提醒、安全、奖励分别用什么主色和光线。
- 需要独立的后期包装节点承接标题、数字、字幕和关注 CTA。

### 2.5 鞠躬游戏：现实动作进入游戏规则空间

**观察**

- 中国年轻女性与柯基在客厅完成弯腰、踏步、左右移动和回扑。
- 地面出现发光游戏圈，空间升级为竞技场，并出现计分板/HUD。
- 失败或冲突用地板碎裂、暂停感和人物近景反应表达。

**导演方法推断**

- 先用真实动作建立规则，再用游戏化空间放大关系，而不是一开始就把角色放进随机炫光场景。
- 人与狗的动作具有响应关系：主人移动是原因，狗转向/追扑是结果。
- HUD 和数字应后期叠加；发光圈、地面能量和破裂可以作为场景内真实反馈生成。

**画布启示**

- 视频提示词要包含“谁先动、谁响应、响应延迟、空间反馈”，而不只是并列描述两个人物。
- 双角色镜头需加入动作归属校验，防止动作错绑。

### 2.6 挑食心理战：把抽象博弈变成道具尺度变化

**观察**

- 柯基与中国女性主人围绕食盆、零食和等待展开冲突。
- 欲望用爱心眼和零食军团表达，规则用墨镜权威形象和巨大闹钟表达。
- 结尾由牵引奔跑升级为巨石追逐，放大“消耗体力”的概念。

**导演方法推断**

- 心理概念通过道具阵营和尺度变化落地：食物阵列代表诱惑，闹钟代表等待，巨石代表体力压力。
- 每次升级仍围绕同一剧情目标，不随机添加装饰。

**规则**

- 包装元素必须回答“它证明了哪一个因果”，无法回答则删除。
- 巨物、阵列、光环等强包装每镜只保留一个主视觉中心，避免元素堆砌。

### 2.7 夏季禁忌：环境危险必须真实作用于角色

**观察**

- 剃毛通过狮子画像反射和破裂反馈表达；噪音由飞机压境表现。
- 高温通过灼热太阳、道路火花、熔岩地面和身体骨骼/热量透视表现。
- 清洁风险通过蜡烛、泡沫、烟雾和灼伤反应表现。

**导演方法推断**

- 环境不是背景板，而是会产生光、热、冲击、烟雾和位移的作用源。
- 风险镜头常采用低机位追拍、近景惊恐反应、前景掠过和强速度线。

**画布启示**

- 生图提示词必须写出“环境作用发生前”的空间关系。
- 视频提示词必须写出环境反馈的启动时机，例如脚掌落地后才出现火花，而不是一开始满屏火焰。

### 2.8 洗爪护理：从微距证据到完整解决方案

**观察**

- 开头用肉垫微距和发光脚垫建立问题，随后是擦拭、泡沫、流泪和出汗。
- 中段切入皮肤裂口、细菌拟人空间和感染入口。
- 后段回到草地、毛巾、护理油、日历和健康肉垫，形成问题到修复的闭环。

**导演方法推断**

- 长视频仍沿用“现实问题 -> 身体证据 -> 语义切片 -> 操作步骤 -> 结果奖励”。
- 产品不应突然植入；先建立肉垫损伤证据，再让护理品进入解决动作。

**规则**

- 产品型文案需要额外输出“问题证据帧、使用动作帧、结果帧”，不能只生成产品摆拍。
- 体内/微观世界可改变场景，但角色资产、主色语义和因果必须连续。

### 2.9 危险气味：把无形气味变成有方向的攻击

**观察**

- 橘子皮、香水和酒精通过绿色骷髅烟雾、发光液体、喷射光束和白色烟柱表现。
- 狗的反应依次出现后仰、闭眼、眩晕螺旋眼、倒地与求救。

**导演方法推断**

- 无形概念必须有来源、运动方向、接触部位和结果。
- “难闻”不是一个画面；“绿色雾从喷瓶冲向鼻尖，狗后缩并闭眼”才是可拍动作。

**逆向视频蓝图**

`主人按下香水喷头，一束细密绿色雾从画面右侧射向哈士奇鼻尖；狗先抽动鼻子，随后猛然后仰、连续眨眼并用前爪挡住口鼻，耳朵贴后。镜头从喷头微距快速横移跟到狗的面部，雾气经过处的暖色客厅短暂染成病态绿色，最后停在狗趴地喘气的中近景。`

### 2.10 幼犬到家：用证据变化推进新手流程

**观察**

- 开头俯拍纸箱与用品清单，再用幼犬眼睛微距建立脆弱感。
- 洗澡风险切到医院，换粮风险切到胃部拟人空间，外出风险切到寄生虫与病原体空间。
- 强行摸抱通过手指、张嘴、咬合和安抚手势推进；结尾用雪地剪影、金色光环和温柔家居完成安全承诺。

**导演方法推断**

- 流程类内容不是平铺五条建议，而是让每条建议都有错误动作和正确替代动作。
- 幼犬资产必须固定具体品种、年龄阶段、毛色、耳形、体型和项圈，不允许写“同一只狗”代替视觉描述。

**画布启示**

- 项目资产锁定必须输出可直接复用的完整描述，而不是关系代词。
- 每个禁忌镜头最好包含“错误行为”和“立即反应”；正确做法可作为下一镜或结尾奖励。

## 3. 对标作品的导演语法

### 3.1 信息必须先变成可见命题

模型先回答：“观众在这一镜必须亲眼看懂什么？”

错误命题：`牛油果对狗有害。`

可见命题：`狗刚靠近牛油果就被绿色毒雾逼退，身体明显失衡。`

只有得到可见命题后，才能写参考图和视频提示词。

### 3.2 微剧情公式

每个知识点优先采用：

`欲望或误判 -> 动作前势 -> 核心动作 -> 物理反馈 -> 夸张反应或结果 -> 稳定落幅`

清单类视频可补充：

`错误项（危险色） -> 身体或环境证据 -> 正确项（安全色） -> 奖励性结尾`

### 3.3 四级可见证据

1. **行为与实物**：闻、咬、舔、跑、停、退、扑；水果、食盆、脚垫、泡沫、牵引绳。
2. **身体绑定状态**：肉垫发光、腹部光团、骨骼/器官透视、眼神脉冲、眩晕。
3. **道具夸张与环境反馈**：巨大时钟、零食阵列、毒雾、灼热地面、破裂地板、烟团。
4. **完整语义切片空间**：体内世界、危险骷髅空间、游戏竞技场、细菌世界、梦境或心理空间。

导演应选择能讲清信息的最低证据等级；证据不够才升级。第四级是主场景，不是“贴纸”，可占 30%-100% 画面。

### 3.4 镜头节奏公式

对标样本平均接近每秒一次视觉变化。不能把这个结论误解为“在一条 4 秒视频提示词里塞四个不同场景”。正确做法是分两层：

- **生成镜头**：3-5 秒连续时空，只保留一个核心动作和最多一种主运镜。
- **剪辑微镜头**：从生成素材中截取 0.8-2.5 秒，或为道具特写、反应近景、身体证据和语义切片单独生成素材。

一个 4 秒口播段落可由 1 个主镜头加 0-2 个插入镜头组成。是否加插入镜头取决于信息密度和证据等级，不机械固定。

### 3.5 机位与运镜

- 道具危险：微距或低机位，先显示来源，再跟随到接触部位。
- 情绪反应：中近景或面部近景，允许短促推近。
- 追逐与游戏：低机位跟拍、横移或短距离环绕；最多组合两种摄影机运动。
- 体内/微观证据：俯拍、穿越或缓慢推进，避免和高速环绕叠加。
- 每镜必须有稳定落幅；生成视频不是永无止境地运镜。

### 3.6 角色与动物表演

- 人物资产写明族裔/国籍视觉特征、性别、年龄段、脸型、发型、服装、配饰和体型。
- 动物资产写明具体犬种、年龄阶段、毛色分区、耳形、口鼻、眼睛、体型、项圈或固定饰物。
- 普通宠物保持自然四足犬科骨架。可以夸张眼神、耳朵、尾巴、口鼻和前爪动作，但禁止无依据的人形躯干、双足站立、人手、人鞋和人类服装。
- “同一个人”“同一只狗”“那个角色”只能作为关系说明，不能代替视觉资产描述。

### 3.7 包装与后期分层

**生成层允许**：烟雾、闪电、碎裂、能量圈、体内透视、巨大化道具、场景色温变化、细菌空间。

**后期层负责**：标题、排行数字、可读字幕、价格牌、HUD、关注提示、转场字卡、音效点和统一调色。

图像模型不应承担稳定生成可读中文的任务。提示词应预留字幕安全区，但不要求模型画文字。

## 4. 两类提示词的明确边界

### 4.1 生图提示词

生图提示词回答：`动作开始前最有张力的一帧长什么样？`

必须包含：

`具体主体资产 + 单一姿态/表情 + 唯一环境 + 关键道具关系 + 可见因果证据 + 必要包装的静态形态 + 景别机位 + 构图层次 + 光线 + 色彩 + 材质 + 画幅`

不得包含：

- 时间过程和连续动作；
- “先……然后……”式视频指令；
- 运镜；
- 工作流、节点编号、模型协议；
- 候选方案和可读字幕；
- “同一只狗”这类无法被图像模型落实的空泛关系词。

建议长度 120-280 个汉字；完整语义切片可放宽到 380 个汉字。

### 4.2 视频提示词

视频提示词回答：`从这张参考图开始，角色和摄影机接下来怎么演？`

必须包含：

`动作前势 + 至少两个有先后关系的具体动词 + 方向/速度/幅度 + 道具或环境反馈 + 情绪反应 + 一种主运镜 + 稳定落幅`

推荐结构：

`角色立即做 A；随后做 B；道具/环境因动作产生 C；摄影机从某机位执行一种主运镜；最后稳定在结果画面。`

不得把以下内容作为正文主体：

- 重复整段角色设定；
- 解释“必须使用参考图”的系统协议；
- 静态环境长描述；
- 节点名称、自动开关、模型名称；
- 长串负面词；
- 多个不连续场景和多个时间点。

建议长度 80-260 个汉字；复杂镜头不超过 400 个汉字。

### 4.3 图与视频的呼应标准

1. 参考图必须呈现视频第一动作的前势。
2. 两者的角色、场景、道具、光线、色彩和包装载体必须一致。
3. 图像中的道具位置必须支持视频动作方向。
4. 视频可以让静态包装启动、扩散或破裂，但不能无依据重新设计画面。
5. 下游按 JSON 字段直接使用 `imagePrompt` 与 `videoPrompt`，不得经过第二个 AI 组装器改写成说明书。

## 5. 导演智能体的目标结构

导演接收变量：

- `sourceCopy`：用户文案；
- `aspectRatio`：16:9、9:16 等；
- `animationStyle`：用户在抽屉选择的动画风格；
- `performanceMode`：动物自然表演、拟人角色等；
- `durationPolicy`：口播语速与镜头时长；
- `referenceAssets`：可选的角色、场景、产品或动作参考。

导演内部工作顺序：

1. 逐句分析事件、因果、情绪、角色关系和信息层级。
2. 提取并锁定具体角色、动物、服装、道具、场景、材质、光线和色彩资产。
3. 把文案拆为语义完整的口播段，避免只按字数硬切。
4. 为每段生成可见命题、镜头职能、证据等级和微剧情动作。
5. 判断需要一个主镜头，还是主镜头加插入镜头。
6. 先写动作和摄影机计划，再从动作前势反推参考图。
7. 输出 `imagePrompt`、`videoPrompt`、声音提示、剪辑落点和验收标准。
8. 全部通过结构与质量校验后，一次性加载到画布。

稳定 JSON 契约必须按字段名识别，至少包含：

```json
{
  "contractVersion": "anime-director-v1",
  "projectBible": {
    "characters": [],
    "characterBible": "",
    "environmentBible": "",
    "visualBible": "",
    "packagingBible": "",
    "editorialBible": ""
  },
  "segments": [
    {
      "narration": "",
      "visualShots": [
        {
          "visualMode": "continuous_story",
          "shotRole": "setup",
          "visibleProposition": "",
          "evidenceLevel": "physical_action",
          "directorDecision": "",
          "cameraPlan": "",
          "keyframeMoment": "",
          "imagePrompt": "",
          "videoPrompt": "",
          "effectsPrompt": "",
          "motionPrompt": "",
          "soundPrompt": "",
          "editPrompt": "",
          "qualityCriteria": ""
        }
      ]
    }
  ]
}
```

字段可以向后兼容新增，但不能靠提示词段落标题或输出顺序解析。

## 6. 当前画布工作流审计

### 6.1 已具备的主干

当前画布已经包含：

`完整文案 -> 导演分析 -> 全片角色/风格资产 -> 角色定妆图 -> 口播分镜 -> 视频提示词 -> 参考图提示词 -> 参考图 -> 视频`

它解决了“文案是否能拆开”“图片和视频有没有字段”“角色资产能否复用”等基础问题。结构化 JSON 与卡片字段直连的方向是正确的。

### 6.2 当前缺口

| 层级 | 当前状态 | 直接后果 | 必须改造 |
| --- | --- | --- | --- |
| 导演决策 | 藏在长提示词或不可见 | 用户看不到为什么这样拍，质检困难 | 每镜增加导演决策卡 |
| 视觉密度 | 一段口播基本只对应一条视频 | 节奏慢，无法接近约 1 秒一次的变化 | 支持主镜头与插入镜头 |
| 图视频呼应 | 有字段但缺可见校验 | 图是静态说明，视频又重新设计 | 增加动作前势一致性检查 |
| 候选策略 | 角色图可候选，分镜图多为单张 | 一次生成失败直接污染后续 | 关键帧默认 2-3 候选再选优 |
| 视频质检 | 生成成功即视为可用 | 角色漂移、动作错绑、尾帧崩坏仍进入成片 | 增加视频质检与局部重试 |
| 后期剪辑 | 依赖外部软件，画布无计划 | 标题、数字、节奏、声音和色彩无法统一 | 增加成片装配节点 |
| 声音 | 仅有提示或完全外置 | 动作没有声音落点，节奏不完整 | 每镜输出环境声/动作声/转场音点 |
| 参考视频 | 当前主链只用图片参考 | 难以稳定复刻动作节奏和运镜 | 增加可选动作/镜头参考输入 |
| 成片验收 | 只验接口和节点数量 | “测试通过”不代表成片质量通过 | 增加视觉与成片验收清单 |

### 6.3 现有流程为什么不能直接承诺对标结果

当前主链能得到每段口播的一张图和一条视频，但对标作品的质量来自完整系统：具体资产、动作戏、语义证据、高频切换、声音点、字幕层、统一调色和不合格素材淘汰。只生成一轮单镜头，没有候选、剪辑和质量门禁，结果只能是“素材方向接近”，不是“成片稳定复刻”。

## 7. 目标画布：一条龙生产链路

### 7.1 项目层

1. **文案输入**：原文、画幅、风格、时长、目标平台。
2. **导演分析**：事件、因果、情绪曲线、叙事类型、视觉难点。
3. **资产圣经**：具体人物/犬种、固定外貌、道具、场景、材质、色彩语义。
4. **栏目包装圣经**：标题安全区、编号样式、危险/安全色、CTA、字幕布局。
5. **剪辑节奏圣经**：平均镜长、主镜/插入镜比例、转场方式、声音策略。

### 7.2 分镜层

每个口播段按以下顺序生成：

`口播 -> 导演决策 -> 参考图提示词 -> 参考图候选 -> 选优/锁定 -> 视频提示词 -> 视频候选 -> 质检/局部重试 -> 剪辑落点`

导演决策卡必须显示：

- 可见命题；
- 镜头职能；
- 证据等级；
- 主动作与反应；
- 机位与唯一主运镜；
- 包装触发方式；
- 需要的插入镜头；
- 图视频一致性验收标准。

### 7.3 成片层

`全部已通过的视频 -> 成片装配 -> 字幕/标题/HUD -> 声音与调色 -> 导出 -> 成片验收`

成片装配节点输出：

- 镜头顺序与实际使用区间；
- 口播和画面时间轴；
- 标题、编号和 CTA 的后期位置；
- 音效点、环境声和音乐强弱；
- 统一色彩与亮度策略；
- 不稳定开头/尾部的裁切建议；
- 缺失素材与必须重生成的镜头。

### 7.4 批量生成策略

- 批量生图：任务独立并发，提交间隔 5 秒，不等待上一张生成完成；失败只影响当前节点。
- 批量视频：仅对已锁定参考图的镜头提交，任务独立并发，提交间隔 8 秒；失败只局部重试。
- 全部生成：阶段串联，阶段内部并发。角色图全部确认后再生成分镜参考图；参考图全部确认后再生成视频；视频通过质检后再进入成片装配。
- 单张/单条手动生成：不受批量阶段门禁阻断，但必须显示失败原因和请求日志。

## 8. 视频生成环境规划

### 8.1 生成素材配置

- 角色定妆：每个角色 2-4 张候选，固定画幅、全身比例和识别特征。
- 分镜参考图：普通镜头至少 2 张候选；复杂双角色、强透视或完整语义切片至少 3 张。
- 视频：重要镜头至少 2 条候选。高动作镜头生成 3-5 秒，成片可只取 0.8-2.5 秒最稳定区间。
- 素材冗余：完整项目建议生成成片时长的 2-3 倍原始视频素材，以便剪掉动作漂移和不稳定首尾。

### 8.2 模型输入优先级

1. 角色/首帧参考图，锁定角色、场景、道具、材质和光色。
2. 动作清楚的视频提示词，只描述接下来怎么演。
3. 可选参考视频，提供运镜、动作节奏或转场参考；不能替代角色参考图。
4. 可选声音参考或声音提示，用于动作声和环境声设计。

### 8.3 质量门禁

**参考图通过条件**

- 具体犬种/人物身份正确；
- 四足动物无错误人形化；
- 画幅为真实 16:9 或 9:16，预览容器按原图比例显示；
- 道具位置支持下一步动作；
- 包装由语义触发且只有一个主视觉中心；
- 没有不可读文字、额外肢体、角色重复或身份漂移。

**视频通过条件**

- 首帧继承参考图；
- 动作主体和动作归属正确；
- 至少有两个清楚的连续动作；
- 环境反馈在动作之后触发；
- 运镜不超过两轴组合，近景不做大幅环绕；
- 角色在最后一秒不崩坏，并有可剪辑的稳定落幅；
- 没有随机换景、角色变脸、道具消失和无依据文字。

**成片通过条件**

- 前 1-2 秒建立冲突或反常识钩子；
- 每个知识点都有可见证据，不是角色站着讲解；
- 连续 3 秒以上无视觉变化时必须有明确剧情理由；
- 字幕、编号和标题在后期层统一；
- 危险与安全色彩语义一致；
- 音效落在动作、碰撞、闪现、破裂和转场节点上；
- 口播、镜头和包装互相证明同一语义。

## 9. 能力边界与交付判断

### 9.1 当前能做到

- 从任意狗相关文案提取具体角色和资产；
- 输出结构化分镜、参考图提示词和动作型视频提示词；
- 生成角色图、分镜参考图和图生视频素材；
- 通过字段契约精准加载到画布卡片；
- 使用对标研究形成的微剧情、四级证据和图视频呼应规则。

### 9.2 当前补齐后才能稳定做到

- 一个口播段落使用主镜头和插入镜头形成高密度节奏；
- 自动生成多个候选并按质量标准选优；
- 自动识别角色漂移、动物人形化、错误画幅和动作错绑；
- 在画布内完成时间轴、字幕、标题、音效和调色规划；
- 导出接近对标节奏的完整成片，而不只是下载分散素材。

### 9.3 最终回答

经过导演提示词升级后，智能体可以稳定产出“遵循对标导演语法”的分镜提示词、生图提示词和视频提示词；但提示词相似不等于成片必然同级。要得到对标效果，画布还必须执行候选生成、质量门禁、高密度剪辑和后期包装。本报告给出的目标链路是完整方案，不能再把“接口返回成功”当作“视频验收通过”。

## 11. 验收红线

- 报告必须区分观察、推断和规则，不能把逆向蓝图称为对方原始提示词。
- 画面不能是口播说明卡或连续静态摆拍。
- 角色资产不能使用“同一个人、同一只狗、那个角色”代替具体外貌。
- 普通宠物不能被默认生成人形躯干、人手、人鞋或无依据服装。
- 生图必须是视频动作将发未发的首帧，图视频角色、场景和道具必须呼应。
- 视频提示词第一句必须进入动作，不能先写系统协议或长篇静态场景。
- 包装必须由当前因果触发，不能从图标菜单随机选取。
- 后期文字必须在后期节点实现，不要求生成模型直接画可读中文。
- 批量任务失败只局部回退，不得让一个失败节点终止全部任务。
- 验收必须覆盖真实画布点击、真实请求、真实生成状态和视觉结果，不得用跳过开关节点的单元测试冒充端到端验收。
