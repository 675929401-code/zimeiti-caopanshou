## 目标与归属

在主站增加“发布中心”，入口位于“封面设计”与“漫剧创作”之间，稳定键为 `publish_center`，页面 `/publish-center`。使用现有二级页面页头、桌面布局、账号、会员权限、现金钱包和管理员权限。主站生成素材后，用户在剪映处理，再选择最终 MP4 与封面发布。

不下载或复制第三方仓库源码。通过 AiToEarn 官方公开的浏览器插件接口接入；公开协议来源为 https://docs.aitoearn.ai/zh/use/plugin-publish 。首版实际适配平台仅为 `xhs`、`douyin`、`wxSph`。云端多用户商业许可、额度与凭据尚未验证，保持未配置状态。不得将公开资料或模拟回执当作真实发布成功。

配色补充：发布中心前台固定使用用户截图的白底、浅紫与粉紫渐变风格；主站主题切换后仍保持固定配色。后台继续现有后台主题和布局。截图中的淘金广场接单、广告主与佣金业务不在本轮范围。

## 影响链

业务与权限：现有会员功能权限 + 独立发布执行额度 → 组件：发布工作台、套餐购买与管理员发布配置 → 主题：局部 CSS Module，复用 `SubPageHeader` → 路由：`/publish-center`、`/api/publish-center`、`/api/admin/publishing` → 存储：新增发布专属表、owner 隔离草稿/账号摘要/套餐版本/权益/任务 → 计费：现有现金钱包 + 单事务购买套餐 → 验证：真实本地页面、数据库事务负例、零外部网络插件替身 → 发布：仅本地构建与验收。

共享导航、权限映射、后台入口、迁移执行、版本、构建与端口由根执行方单独负责。前台、后台面板与新服务代码独立分工；所有人保留既有混合工作区差异。

## 产品合同

1. 最终文件仅在浏览器内存中预览并交给插件；草稿保存文件名、大小、类型等元数据，刷新后要求重新选择文件，不能声称已上传。首版不扩大现有内存上传限制。
2. 用户只连接插件当前登录账号，发布前展示并再次核对平台 UID；不能假设插件支持按站内账号 ID 自动切号。插件返回的 Cookie、Token、原始错误和原始结果不得进入主站存储、日志或遥测。
3. 套餐是后台创建的版本化商品，初始无在售商品。售价、执行次数、期限、平台范围均由管理员配置。现有会员权限模板和历史快照不自动扩权。
4. 会员使用现有充值入口补充现金余额，以原子 RPC 在同一事务内完成钱包扣款、购买记录与权益发放。保留原支付渠道、回调、账本及已有 ID，不新增钱包，不修改外部支付合同。
5. 执行额度按“一个平台账号的一次提交准入”记录。此为待管理员启用销售时确认的本轮工程预案，并非用户已确认的商业售价或退款政策。提交前明确显示消费次数与待核对规则。
6. 执行首次准入才消耗额度并返回一次执行许可。相同幂等请求只返回原任务，不重复发许可。请求丢失、浏览器中断或平台结果未知时保留原任务，不自动重发、返次或退款。
7. 插件回执只标记浏览器报告，不能冒充服务商已核验成功，也不能据客户端成功或失败决定现金退款。
8. 管理员看到渠道配置、采购入口、商品与任务摘要；会员只看自己的账号、草稿、额度和发布记录。后台敏感读写使用既有权限与二次验证，不能只靠隐藏按钮。

## 启用边界

执行与销售默认关闭。外部执行同时需要管理员配置和运行环境显式开关；本轮不启用、不真实发帖、不调用付费服务。缺迁移、缺配置、无权限、无额度都返回可解释的稳定状态。后台可保存配置、套餐草稿与官方购买渠道，不伪造充值或服务开通结果。

采购主体为站方；会员在本站使用发布权益。官方发布教程与接口页存在人工增购和未来积分扣费两种表述，成本与商业接入条件保持待确认，不硬编码为已生效售价。

## 验证与回退

验证未经授权/跨 owner/价格篡改/同键异参、并发购买与执行防重、扣款与权益同事务、过期与额度不足、数据库普通角色无直接权限、插件敏感字段剥离、账号切换、缺许可不执行、丢响应不重发。零网络替身与真实供应商验收分开记载。
