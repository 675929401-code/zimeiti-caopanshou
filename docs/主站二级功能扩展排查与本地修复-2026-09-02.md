# 主站二级功能扩展排查与本地修复

日期：2026-09-02。本文补充《本地主要功能修复与真实验收-2026-09-02》，不把此前限定型号的成功扩展为所有型号或全部功能通过。

## 当前结论

F 盘当前源码继续作为本地升级版本，5000 使用本地独立数据副本。视频制作和分镜的已验收路径可以使用；全站仍不能统一宣称“除上游或密钥之外全部正常”。扩大检查发现并修复了此前没有覆盖的页面初始化、任务取消、结果恢复、语音保存、Skill 版本保存等本地问题。

本轮没有修改生产服务器或生产数据库，没有推送 Git、部署或覆盖服务器。新语音结果按网站既有流程保存到配置的对象存储，属于本次生成的测试资产。

## 本轮实修的本地缺陷

1. **封面任务缺少稳定请求身份、模型字段误读。** 修正公共模型 DTO 名称、价格与参考图能力；提交前保留完整原请求、幂等键及 trace，未知状态不另建生成，服务端允许恢复后才同键恢复，确认资产与历史后才显示完成。
2. **取消任务过早显示成功。** 前端等待明确取消终态；后端等待上游确认，再以原状态条件更新，防止覆盖并发完成结果。没有配置取消能力时不猜测支持；视频状态订阅不再因等待 5 分钟自动请求取消，或因 30 分钟直接写过期。
3. **图片刷新恢复丢参考图。** 从原请求指纹中的完整 JSON 恢复模型、规格和原参考地址，避免重新上传后改变同键请求内容。视频历史刷新同时保留接口已返回的尾帧。
4. **分段页面初始化丢输入、身份未恢复即提交。** React 接管前禁用输入并提供状态；认证恢复前禁止语义请求；游客只能明确使用本地规则预览，不创建匿名上游请求。两个入口实际输入保持一致。
   - 共享草稿 Hook 改为服务端与浏览器首次渲染一致，挂载后再恢复 sessionStorage；完成恢复前禁止把默认值写回，保留草稿和刷新后的结果。两个分段入口实际带草稿双刷新均通过，无捕获到的 hydration 错误。
   - 结果卡区分目标范围与语义宽限：本次 42/46 字在目标内，50 字显示“语义宽限内”，不再把超出目标的段落标为目标达标。该显示修正不改变算法或已完成结果。
   - 确认用户身份后立即解除认证等待，不再额外等待余额查询完成。真实源码隔离验证了余额 Promise 悬挂时的按钮状态；此前一次页面等待超时没有复现，不能将它的原因直接归到余额查询。
5. **语义服务本地网络路径不一致。** 旧路径只校验系统 DNS 后原生请求，在本机虚拟地址环境中直接被阻止。改为校验公网地址后固定连接的 JSON POST，HTTPS、请求和响应限额、禁止重定向和自动重试；规范完整 API URL 和服务端密钥引用；区分未发请求与上游状态不明。
   - DeepSeek 官方 V4 默认开启思考模式。针对这个只需分组 JSON 的小任务显式关闭，其他供应商不附加该字段；保留终止原因和校验诊断。依据：[官方思考模式协议](https://api-docs.deepseek.com/guides/thinking_mode/)。原回退任务没有保存终止原因，不能事后断言它必定因思考占满额度而截断。
6. **语音有音频却保存失败。** 将 MP3 的 `audio/mp3` 别名规范为 `audio/mpeg`，保留内容签名校验；单人模式使用实际选中的模型；试听按字节拼接 Base64 分片、保留错误，部分输出后不自动换模型重做。
7. **语音选项与现有能力不符。** 完整文件交付表单移除不可保存的裸 PCM；长文本说明改为真实支持的 5000 字符同步合成。新增鉴权、分页、可刷新签名的“生成历史”入口，支持播放、下载和错误重试。
8. **Skill 下一版草稿 CAS 合同冲突。** 新专用数据库函数在同一事务检查包更新时间、归属和已发布基线，随后创建下一版；旧草稿编辑保留原严格并发校验。
9. **配置与状态假就绪。** Skill 目录 HTTP 200 但带迁移未就绪标识时显示真实警告；语音状态同时检查必要函数、表和字段，不能仅有密钥就允许提交。

修改前快照和 SHA 位于 `任务快照/` 与 `.codex-backups/`。修改清单分别记录在三个域的报告中，未覆盖原有其他改动。

## 尚不能作出的结论

不能声称所有模型均支持其界面全部参数，所有普通用户扣费和退款完成对账，或所有二级页面都已执行过生成。声音复刻/设计受现有商业许可限制；没有伪造授权。封面、图片刷新恢复、取消等修复已经做实际函数回归，但不能把隔离测试当成各型号真实上游取消或重新生成。
