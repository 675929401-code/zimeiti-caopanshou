# 高能导演：20维制作闭环与验收口径

本轮从已验收的本地 r90 / R001303 续接。此文记录候选设计与验收方法，不替代后台配置、当前源码身份、交接回执或实际样片。

用户目标是保持高能动画的稳定风格，让变化的口播成为可表演、可拍摄、可核对的故事。普通模式直接输出分段生图与视频提示词；参考模式一次交付角色三视图和全部分镜、视频提示词，以完整待执行计划推送到工作台。实际生成时先完成人物、宠物三视图并逐项确认，然后在工作台继续分镜与视频，无需返回智能体。男性角色默认清爽帅气，女性默认时尚时髦，用户明确的年龄、外貌、服装与其他要求优先。

| 维度 | 导演要决定什么 | 结果在哪里 | 如何判断 |
|---|---|---|---|
| 1 原文事实 | 哪些事实、段界与角色不可改 | 原始 input 与逐段 narration | 与接收卡逐字对账 |
| 2 语义重点 | 本段让观众理解什么 | semantic_event 与双 Prompt | 人工核对语义，不靠关键词得分 |
| 3 目标与阻碍 | 谁想做什么、什么阻碍或预期出现 | 动作起点、主动作与事件 | 看是否有真实因果 |
| 4 全文故事线 | 本段铺垫、升级、揭示还是保留张力 | 原段顺序、段末状态 | 中间段不提前解决全文冲突 |
| 5 高能指纹 | 夸张造型、快速变化、重量、反应差 | 所选风格、动作与剪辑 | 与基线和对标的实际画面比较 |
| 6 人物视觉资产 | 样貌、发型、全套衣着与识别点 | 文字选角、wardrobe_plan、身份锁 | 单次选择、逐段完整复述、备注优先 |
| 7 宠物视觉资产 | 犬种、毛区、耳尾、项圈与结构 | 宠物身份锁、参考资产 | 无身份漂移，实际画面无解剖错误 |
| 8 生活情境 | 入镜理由、空间和持有物 | scene_lock、动作起点 | 场景承载事件，不是无关背景 |
| 9 动作预备与发力 | 支撑、方向和主要变化 | action_chain.setup / drive | 有具体演法，不只写“高能” |
| 10 接触与余波 | 触点或约束、反作用与落点 | contact / feedback / settle | 图和视频中能看到对应反馈 |
| 11 人物表情 | 刺激、前态、眉眼嘴角、释放 | expressions 中人物记录 | 表情随事件变化，不只贴情绪标签 |
| 12 宠物表情 | 视线、耳根、短暂嘴部、尾根、重心 | expressions 中宠物记录 | 保留四足与犬种结构，避免套人脸 |
| 13 双方反应差 | 谁先行动，谁后理解 | 表情触发与动作先后 | 看得出错位、回应或期待变化 |
| 14 道具与包装 | 用什么解释语义、从何进入、怎样变化 | semantic_visualizations 与执行正文 | 现实物优先，有触发和生命周期 |
| 15 构图与装饰 | 主峰剪影、前中后景、证据与安全区 | 生图逐格画面 | 装饰不遮挡脸、手爪和触点 |
| 16 镜头调度 | 景别、轴线、主运镜与切点 | 唯一 shot_time_ranges、视频正文 | 每镜一个主动作和主运镜，切点有目的 |
| 17 节奏与声音 | 快慢反差、反应停顿、同步拟音 | 视频正文与时间轴 | 实片逐秒观看和听音；不伪造声音能力 |
| 18 状态接力 | 角色位置、持有者、方向与未完成目标 | continuity_links、end_state | 后段从已有状态继续，有依据才跳时空 |
| 19 记忆点与变奏 | 哪个瞬间一眼能认、不同文案怎样变 | peak_shot_id、image_excerpt | 缩略图可读；不同文案不机械套同一演法 |
| 20 闭环与结果留存 | 摘要、正文、推送、保存是否一致 | performance_plan → directorExecution → 项目 | 引用逐字核对、刷新恢复、分层验收留痕 |

表演计划使用 `storyboard_performance.v1`：一段一个主峰，复用现有镜头 ID 和时间轴。五步动作链与每个角色的触发、前态、峰值、释放逐字存在于视频节选；表情峰值存在于图片节选；两段节选逐字对应实际 Prompt。计划不会另造时间轴，也不会把剧情表情写进中性三视图的永久身份。

四种主峰是动作变化、反应改变、证据揭示、压住未发的张力。它们服务文案，不构成每段必做四件事的配额。短暂安静可以形成对比；全片反复轻走、歪头、微笑也不能因此称为高能。装饰只解释速度、受力、感知或关系，具体表现随语义选择。

用户追加指出，创作内容不应被生产规范淹没，且审片图同时需要中文语义摘要与英文技术注释。后续修订以中文书写提示词主体，把本段可见事件提到前面，逐格具体说明动作、表情、触点和信息变化；完整身份锁与统一规格仍可独立执行。每格88%用于剧情画面，12%为固定三行审片底栏：6–12字中文重点、英文镜号与机位、英文动作短句。中文重点是语义提炼，保留原文的可能性与限制，不等于照搬长口播，也不占剧情物件文字配额。最终视频只取剧情图像，不带中文摘要、英文注释、镜号或格线。参考模式中性三视图继续保持无字。

旧版 F01–F06 / M01–M04 是文字服装目录。本轮迁移为宿主可以调用的单一数据源，按语义筛选后可复现地选择一次；目录仅补未指定项，用户定制不受旧闭集和禁裙条款限制。动画材质映射保留已选服装的颜色与结构。完整计划以稳定角色 ID 贯穿全部分段，执行时绑定已保存且明确确认的图像身份，不因阶段切换、目录或种子变化重选。

完整计划使用 `storyboard_director_plan.v1`，其 `planned` 阶段仅表示文字计划已交付，不代表图片已生成。推送本身不调用生成模型。工作台“连续制作”先确认所选模型与剩余任务费用，按参考图、明确采用、分镜图、视频顺序执行；结果未知或失败即停止，刷新恢复已保存结果，新请求需再次确认。历史资产包继续兼容；满足原接收卡、历史时间与完整双提示词条件的普通模式旧回复，可明确作为历史草稿导入，不补造表演与镜头证明，也不启动连续制作。

确定性门禁只说明结构完整、角色与镜头 ID 合法、文字对应、模式正确、数据可恢复。语义准确、动作力度、表情感染力、画面美感和对标观看体验仍需独立审阅。不得用自动命中动作词、模型自评分或字段齐全宣布艺术质量优秀。

验收分四层保存：工程合同；真实智能体文本；真实生图；真实视频与声音。跨文案至少覆盖行为机制、关系情绪、观察或证据揭示，以及一组多段连续故事。作者编写的工程示例只用于验证接口，不能冒充真实智能体输出或已生成作品。

已知真实生成限制沿用 r90 回执：此前文本请求在上游前受预留额度限制；此前生图请求到达渠道后返回参数错误。未经新的真实生成与观看，当前候选不能宣称实现了对标成片效果。修订、配置生效时间、构建和浏览器结果以本轮不可变交接为准。
