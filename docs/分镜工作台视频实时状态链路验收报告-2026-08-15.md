# 分镜工作台视频实时状态链路验收报告

日期：2026-08-15

## 根因

1. 工作台没有消费既有 SSE 状态流，只依赖低频轮询。
2. 统一视频适配器只读取根级状态；上游常见的 `data.status`、`data.video_url` 没有被正确识别。
3. 合法公网 `content_url` 会被错误改写为 API 端点域名，导致查询地址失效。
4. 未知响应和临时 HTTP 异常被统一伪装成“排队中”，真实错误没有传到前端。
5. 上游进度同时存在 0-1 与 0-100 两种格式，旧界面会把 0.42 显示为 0.42%。
6. 异步任务记录采用后台写入，用户提交后立即终止时可能还查不到任务。

## 修复

- SSE 实时状态优先，连接异常后自动降级为主动轮询。
- 支持根级和嵌套状态、成功地址、失败原因、余额不足、审核失败及临时 5xx。
- 仅修正内网查询地址，保留上游返回的合法公网地址。
- 明确区分排队、生成、成功、失败、取消和临时查询异常。
- 进度统一为前端百分比；显示等待时长和最近一次上游回报时间。
- 生成中按钮切换为“终止生成”，同时终止本地追踪并请求上游取消。
- 提交接口等待本地任务追踪记录写入后再返回，降低立即取消竞态。

## 无费用验收

- 适配器：嵌套成功、成功待地址、审核失败、余额不足、进度、临时上游异常，6/6 通过。
- 浏览器：成功、失败、余额不足、主动终止，4/4 通过。
- 目标 ESLint：0 错误。
- `/storyboard-workbench`：HTTP 200。
- 付费调用：0。
