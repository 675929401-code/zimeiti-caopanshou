# 故事板 v4.1 对标 A/B 验收报告

## 验收对象

- 对标证据：用户提供的三张清晰 4/5 格高能 3D 动画故事板。
- 固定测试口播：狗狗舔墙、啃土、钻花盆、满鼻泥在客厅打转，先检查饮食和身体状况，不盲目乱补。
- 导演模型：GPT-5.6-Sol 故事板长输出。
- 生图模型：两轮均为 GPT-Image-2 渠道 A（密钥 F），16:9，1K。
- A 版：v4.0；B 版：v4.1。除导演提示词外，其余变量保持一致。

## 总结结论

B 版通过本轮故事板图片验收，已经从“同一场景换视角”转成“异常、升级、追逐、知识揭示、行动结论”的事件链。它达到对标的核心方法，而不是只复制某个构图：商业级 3D 动画底片、夸张动作漫画层、语义驱动的巨大知识资产和逐格视频执行条同时存在。

这不是宣称像素级一比一。模型随机性、私有训练数据和对方未公开的提示词仍不可复制；当前可验收的是结构、视觉语法、提示词颗粒度和工作流输出接口已经对齐。

## 对标文字含义核验

对标图片每格底部白条中的英文，是该格对应的压缩版图生视频执行指令，不是口播文案，也不是普通图片说明。其语法包含：

`Frame 编号 + 强运镜 + 主体动作 + 次要反应 + 特效运动 + 结果`

画面内部的 `Vitamin A/B/D`、中文警告牌、体重秤、医院牌等，则属于故事板生图 Prompt 的知识资产。v4.1 已按这两个层级分别输出，并且工作台不再二次改写。

## B 版关键帧验收

1. 舔墙异常：贴地近景，墙灰有来源和落点，主人从后景发现问题。
2. 钻花盆：泥块飞向镜头，主人飞扑抓空，事件完成升级。
3. 客厅追逐：泥土旋风、家具和靠垫响应动作方向，不是均匀贴特效。
4. 原因揭示：现实客厅切换为黑金知识舞台，“异食警报”占据视觉中心，柯基急刹错愕。
5. 行动结论：“先检查”蓝金盾牌把食物与健康检查放在保护侧，把盲目补充瓶挡开。

## 当前剩余边界

- 一张 1K 图片内要求五条较长英文，仍会压缩字号；v4.1 已把每条控制在 18 至 26 词，这是清晰度与可执行信息之间的折中。
- 图像模型偶尔会改变极小道具的标签或数量，因此画内中文限制为两个短词。
- 本轮只验收了故事板生图和视频 Prompt 的文字结构，没有消耗视频模型生成 B 版成片；视频效果仍需要在分镜工作台用同一张 B 版故事板做一次 10 秒实片验收。
