# 对标视频提示词逆向拆解与智能体学习方法

## 1. 证据清单

### 已观察证据

- `故事版短视频制作方法.rtf` 已提取出流程文本、残缺故事板 Prompt、对标工作台截图和多张参考图。
- 参考图表现稳定为：皮克斯式高能 3D 宠物科普动画、女性主人加柯基、4 格或 5 格一图多画面、白色分格线、每格底部白色 `Frame N` 英文制作说明条、醒目中文漫画爆炸字牌、金橙放射光、强动作峰值。
- 工作台截图显示：每个镜头卡片先有“分镜提示词（生图）”，生成一图多格参考图后，再解锁“生图参考图（可选）+ 生成视频”。

### 文本证据

- 对标流程文字写明：文案按约 10 秒分段，故事板智能体输出每段提示词，每段提示词先生成一张多格故事板，再使用 Omni 10 秒 1080P 视频模型生成视频。

- 这些英文条不是成片字幕，而是嵌入参考图里的“镜头动作说明”，用于让图生视频模型理解每格的运动方向、动作峰值和特效反馈。

## 2. 当前遗漏

| 维度 | 状态 | 影响 |
|---|---|---|
| 真实参考视频 mp4 | 缺失 | 不能做严格时间码表、动作速度、镜头数和转场验收 |
| 完整对标视频 Prompt | 缺失 | 只能反推结构，不能复原对方完整措辞 |
| 完整智能体输出 | 残缺 | 只能确定稳定格式和核心语法 |
| 多主题样本 | 样本少 | 泛化规则只能先做假设，不能标为 validated_rule |

## 3. 我会如何学习并优化智能体

### 第一步：把一图多格当“视频蓝图”，不是成片格式

一图多格负责锁定视觉锚点：

- 角色是谁、宠物是什么品种、人物服装与表情是否稳定。
- 当前段落有哪些关键动作峰值。
- 场景、道具、特效、中文包装字牌是什么。
- 每个动作峰值下一步会往哪里运动。
- 白色 `Frame N` 英文条说明该格应该怎样动。

视频 Prompt 负责把蓝图转成时间：

- 0-10 秒怎么分配 3-4 个真实镜头。
- 哪个动作先发生，哪个动作后发生。
- 角色怎么预备、发力、反应、急停、收束。
- 镜头怎么推、跟、甩、环绕、俯拍或低机位。
- 特效从哪里出生，什么时候爆发，什么时候消散。
- 成片必须全屏连续动画，不显示多格边框、Frame 编号或说明条。

### 第二步：建立“文案语义到演绎”的路由

每段文案先判断语义任务，再决定画面包装：

| 文案语义 | 默认故事演绎 | 包装触发 |
|---|---|---|
| 提问/钩子 | 主人或路人抛出误解，狗狗反应夸张 | 问号牌、选择牌、对比天平 |
| 误解/反常识 | 错误做法被夸张化演成笑点 | 红叉、爆炸字牌、警告三角 |
| 风险/疾病 | 场景变成知识警报或医学示意 | 警报牌、器官图标、数据仪表 |
| 判断方法 | 用镜头视角直接演示判断动作 | 俯视镜头、轮廓线、尺子、放大镜 |
| 结论/号召 | 人宠同框落点，信息清楚收束 | 结论牌、勾选章、上传/拍照道具 |

### 第三步：把每段统一成“图文视频互锁”

每段必须输出两类 Prompt，但它们不能互相重复：

- 生图 Prompt：讲“看见什么”，强调一图多格、每格动作峰值、构图、特效、道具、中文字牌和 Frame 英文说明条。
- 视频 Prompt：讲“怎么演”，强调 10 秒时间轴、实际镜头数、运镜、动作链、特效生命周期、声音和成片限制。

## 4. 反推的视频 Prompt 母版

```text
使用已生成的一图多格故事板作为唯一视觉参考，生成10秒正常全屏3D动画视频。锁定参考图中的角色造型、宠物品种、服装、场景、道具、中文包装字牌风格、金橙放射光和皮克斯式高能动画质感。成片不要出现多格分屏、白色分格线、Frame编号、英文说明条、工作台UI、字幕或水印。

镜头1（0.0-2.2秒）：从参考图Frame 1的起始姿态开场，用【推近/跟拍/俯拍】建立当前文案的钩子。角色先有一个清楚的预备动作，宠物用耳朵、尾巴、眼睛和重心反应；核心道具或语义字牌第一次出现，特效只从动作接触点出生。

镜头2（2.2-4.8秒）：承接镜头1的运动方向进入冲突升级。人物、宠物或路人必须产生可见互动，不允许只是站着看；使用快速横移、甩镜或撞切强化误解/反常识，包装字牌或警示图形短暂爆发后让位给角色动作。

镜头3（4.8-7.4秒）：进入机制揭示或判断方法。镜头视角必须服务语义，例如俯视、低机位、近景特写、放大镜或对比尺；特效从混乱转为清晰的信息图形，角色表情由惊讶转为理解或警惕。

镜头4（7.4-10.0秒）：完成结论或号召。动作速度放缓，人物和狗狗与核心道具同框；中文重点字牌以对标漫画爆炸牌/金色牌/警告牌形式做最后一次清晰出现。最后0.5秒稳定停留在信息最明确的落幅。只保留自然动作声、环境声和轻微提示音，不要对白、旁白、歌词和口播字幕。
```

## 6. 对标验收方式

### Prompt 层

- 是否每段 10 秒，且只对应一个语义完整段落。
- 是否每段都有独立生图 Prompt 和视频 Prompt。
- 生图是否负责视觉锚点，视频是否负责演绎时间轴。
- 是否默认柯基加女主人，并能按文案改主人性别或狗品种。
- 是否有语义包装生成器，而不是固定复用同一张爆炸牌。

### 图片层

- 版式是否像对标：4格/5格、多格故事板、白色Frame说明条。
- 是否是高能皮克斯式 3D 宠物科普动画，而不是电影分镜草图、黑边故事板或普通插画。
- 中文字牌是否醒目、一秒可懂，并且来自当前文案语义。
- 每格是否是动作峰值，不是同一场景换表情。

### 视频层

- 是否正常全屏连续动画，而不是多格拼贴动图。
- 是否按 10 秒 3-4 镜头演绎，而不是机械 Frame 1 到 Frame 4 幻灯片。
- 是否保持参考图角色、宠物、场景、道具和风格。
- 是否补足动作链：预备、发力、接触、反应、余波、结尾停留。
- 是否把图上的英文 Frame 条转译为运动，而不是让它出现在成片里。

## 7. 下一步测试门禁

在没有真实参考视频文件前，先做两级测试：

1. `Prompt+图片对标测试`：可以执行，判断智能体是否学会参考图和残缺提示词结构。
2. `视频演绎假设测试`：可以执行，但结论只能写为“与当前推断规则对齐/不对齐”，不能写为“与真实参考视频逐帧对齐”。

拿到真实参考视频后，再升级为：

1. 抽取 0-10 秒关键帧。
2. 建立逐秒表：口播、画面事件、角色动作、镜头、特效、声音。
3. 反推完整视频 Prompt。
4. 回写智能体，并重新测试两段文案。
