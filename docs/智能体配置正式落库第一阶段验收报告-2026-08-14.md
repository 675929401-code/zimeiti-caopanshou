## 3. 未执行原因

当前环境只有：

- `COZE_SUPABASE_URL`
- Supabase service role/anon REST 密钥

当前环境没有：

- `DATABASE_URL`、`POSTGRES_URL` 或 `SUPABASE_DB_URL`；
- 暴露在 PostgREST OpenAPI 中的 `exec_sql`、`execute_sql`、`run_sql` 或 `query_sql` 事务 RPC。

Supabase REST 每次请求都是独立事务，无法保证“创建备份表、写备份、更新 agents、写 prompt_versions”整体原子性。根据任务门禁，禁止用多次 REST 请求绕过单事务要求，因此本阶段停止在执行前。
