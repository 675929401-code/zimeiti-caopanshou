# 故事板参考图反推分析报告

> 研究日期：2026-08-13  
> 研究对象：对标站“故事版 1 / 故事版 2”、帮助中心教程、真实智能体输出截图、三张故事板案例图及对应成片  
> 用途：作为故事版智能体提示词和分镜工作台开发的视觉依据

## 0. 结论先行

1. 对标方案的核心不是“把四张图拼到一起”，而是先把一个口播段改写成一个可表演的微故事，再把故事的连续关键状态放进一张多格故事板中。
2. 格数不是单纯由字数决定。证据显示“故事版 2”固定四格；“故事版 1”的真实输出出现过三格、四格和五格。当前产品目标应采用**语义自适应四至五格**，不再把四格或五格当成用户个人偏好。
3. 四格适合一条完整但简单的因果链；五格适合多一个必要反应、转折、知识可视化或高潮收束。第五格在真实案例中不是“上二下三”的小格，而是**上方 2×2 四格 + 底部横向全宽高潮格**。
4. 参考图同时承担三项职责：角色与风格锁定、动作顺序索引、视频模型的时序地图。它不是最终视频的分屏画面，也不是只供人阅读的普通分镜稿。
5. 对标画面精彩的来源不是多写形容词，而是每格都具备“动作前势或峰值姿态 + 夸张反应 + 物理反馈 + 语义可视化 + 明确机位”。
6. 画面中的英文 `Frame N` 指令条不是最终字幕，而是镜头执行注释。它把本格的运镜、动作和特效压缩成一句话，与后续视频提示词形成对应关系。
7. 不能把语义包装理解成固定贴纸库。问号、桃心、震颤线、局部教学窗、警示牌等只是表达语义的视觉载体，必须由当前文案中的“不可见信息”反推。
8. 现有《10秒故事板导演智能体提示词 v2.1》与真实链路存在关键偏差，不能继续在其上打补丁，应按本报告重新编写。

## 1. 证据与边界

### 1.1 已验证证据

| 证据 | 直接可见事实 | 可信级别 |
| --- | --- | --- |
| 帮助中心“故事版智能体优化更新” | 故事版 2 明确输出“固定 4 格”生图 Prompt 和“对应第 1 格至第 4 格”图生视频 Prompt | 直接证据 |
| 真实智能体回复截图 | 分段 7 为 5 格，分段 8 为 4 格，分段 9 为 5 格；另有分段 12 为 4 格、分段 13 为 3 格 | 直接证据 |

| 工作台实际页面 | 一张故事板作为一个镜头卡片的生图结果，生图完成后在同卡片解锁视频 | 直接证据 |
| 对应案例视频 | 多格故事板被生成成连续的全屏镜头，而不是保留网格分屏 | 直接证据 |
| 对标私有系统提示词 | 未购买、不可见 | 不作原文还原 |

### 1.2 本报告能确定什么

- 可以确定其输入字段、输出外形、画面结构、镜头语法、工作台提交方式和成片行为。
- 可以依据案例反推一套可执行方法论和验收标准。
- 不能声称拿到了对方私有智能体的系统提示词原文。
- 本报告中的“提示词结构”是基于可见结果重建的工程方案，不冒充对方源码。

## 2. 版本差异与格数判定

### 2.1 两个版本不能混为一谈

| 项目 | 故事版 1 | 故事版 2（升级版） |
| --- | --- | --- |
| 可见名称 | 夸张表演版 | 影视级效果 |
| 格数证据 | 真实回复出现 3/4/5 格 | 教程明确固定 4 格 |
| 主要倾向 | 高密度动作、漫画式夸张、语义道具 | 固定结构、电影感镜头、稳定四拍 |
| 使用方式 | 智能体输出 Prompt，再复制到同一分镜工作台 | 相同 |

因此，“有时四格、有时五格”并非教程自相矛盾，而是两个版本与不同语义密度的结果。

### 2.2 当前产品采用四至五格的理由

用户提供的是**已经分好段的口播文案**。每段通常对应一个约 10 秒视频单元。为了兼顾模型可执行性和画面丰富度，当前产品应排除三格，限定为四至五格：

- **四格**：本段只有一条明确因果链，四个状态已能完整表达“建立 → 触发 → 升级 → 结果”。
- **五格**：除主因果链外，还存在一个不可删除的主体反应、知识演示、反转、高潮或向下一段的桥接。
- **禁止凑格**：没有第五个新信息时不得把同一动作换景别重复一遍。
- **禁止按标点机械切格**：一句话可以跨多个视觉节拍，多句话也可以合并为同一动作链。

### 2.3 四格与五格版式

**四格固定版式**

```text
┌──────────────┬──────────────┐
│ Frame 1      │ Frame 2      │
├──────────────┼──────────────┤
│ Frame 3      │ Frame 4      │
└──────────────┴──────────────┘
```

**五格固定版式**

```text
┌──────────────┬──────────────┐
│ Frame 1      │ Frame 2      │
├──────────────┼──────────────┤
│ Frame 3      │ Frame 4      │
├─────────────────────────────┤
│ Frame 5：高潮 / 结论 / 桥接 │
└─────────────────────────────┘
```

第五格使用全宽构图，使结论或高潮获得更强视觉权重。现有提示词中“上 2 下 3”或“上 3 下 2”的定义与案例不符，应废弃。

## 3. 一张多格图真正解决的问题

### 3.1 它不是普通拼图

一张多格故事板提供的是一个完整的控制面：

1. **空间控制**：每格有独立构图，但共享角色、材质、场景和色彩。
2. **身份控制**：模型一次看到全套角色状态，减少逐张生成造成的脸、服装、犬种和道具漂移。
3. **时间控制**：`Frame 1 → Frame N` 明确动作发生顺序。
4. **镜头控制**：每格预先给出景别、机位与动作峰值，视频模型不必从一张静态封面猜完整十秒。
5. **语义控制**：抽象口播被转换成可见道具、局部演示、环境反馈和角色反应。

### 3.2 每格的职责

每格只保留一个决定性瞬间，但这个瞬间必须是视频动作的“起跑线”或“峰值证据”，不能是无动作的角色摆拍。

推荐结构：

`景别与机位 + 明确主体 + 动作前势/峰值 + 可见表情和身体重心 + 关键道具状态 + 环境物理反馈 + 必要的语义可视化 + 光线与色彩`

反例：

`一只狗在客厅里很紧张，卡通风格，电影感。`

可执行表达：

`低机位中近景，三色短腿柯基前爪急刹在玄关地板上，后腿仍向前滑，耳朵猛然竖起，瞳孔收紧，主人刚提起的旅行包占据右侧前景；狗胸口前出现与呼吸同步向外扩散的两圈红色心跳波纹，爪下拖出短促刹车线，门缝冷光与室内暖光形成分离感。`

## 4. 对标画面的视觉语法

### 4.1 微故事结构

每个口播段先被转换成一条可见因果链：

`正常状态 → 触发物进入 → 角色采取动作 → 结果被放大 → 知识点/情绪落地`

画面不是解释文案，而是让角色和道具把文案演出来。

### 4.2 表演强度

真实案例普遍使用以下表演层级：

- 眼睛、眉毛、嘴形先给出清晰情绪方向。
- 耳朵、尾巴、重心和四肢承担第二层反应。
- 毛发、灰尘、食物碎屑、水滴、光线或周围物件承担第三层环境反馈。
- 身体弹性、急停、滑行、后仰、飞扑等形成可读的动作轮廓。
- 夸张服务于动作和知识点，不把动物变成人形角色。

### 4.3 语义视觉化方法

先问一句：**这段口播里，什么重要信息仅靠真实动作仍然看不见？** 只有答案明确时才添加视觉包装。

| 不可见语义 | 合适的视觉载体 | 执行要求 |
| --- | --- | --- |
| 疑惑、无法理解 | 问号、左右对照轮廓、视线往返 | 与角色头部和视线绑定 |
| 紧张、害怕、心跳 | 胸口心跳波、震颤线、汗珠、急刹痕 | 必须由触发物引起，不可凭空悬浮 |
| 喜爱、依恋、恋爱 | 两个主体之间的桃心、靠近轨迹、柔和暖光 | 必须体现双方关系和互动方向 |
| 嗅觉、气味 | 可见气味轨迹、鼻尖微粒、追踪路径 | 从气味源连到鼻部 |
| 肠道、消化、营养 | 友好的局部教学窗、简化管线、食物行进路径 | 只做局部示意，不剖开完整身体，不血腥 |
| 危险、禁止 | 警示牌、阻挡动作、红色边界、风险图标 | 角色必须对警示作出反应 |
| 数值、体重、时间 | 秤、仪表、时钟、计量标记 | 作为可操作道具而非纯文字层 |
| 原因与结果 | 箭头、前后对照、道具状态变化 | 方向清楚且只表达一个因果 |
| 抽象营养概念 | 卡片、徽章、盾牌、骨头图标、发光演示 | 要被角色举起、触碰、躲避或观察 |

语义包装的核心是**进入剧情**：被角色看见、触碰、躲避、追逐或触发。随机贴在画面角落的图标不算包装。

### 4.4 镜头变化

一张四至五格故事板至少包含：

- 两种以上景别；
- 一次明显机位变化；
- 一次主体或道具的方向变化；
- 一次环境反馈或语义可视化；
- 一次能够承担结论的收束构图。

常用组合不是固定模板，但可以作为判断参考：

`全/中景建立 → 跟拍或横移 → 手部/道具特写 → 反应近景 → 全宽高潮或结论`

### 4.5 动作注释条

三张案例图都把一句动作指令放在每格下方独立白色区域，例如：

`Frame 2: Rapid whip pan follows ...`

其作用是：

1. 标注格号，帮助模型和用户确认读取顺序。
2. 用一个强运镜动词和一个主体动作概括本格。
3. 让生图结果直接成为后续视频 Prompt 的视觉索引。
4. 将制作说明放在独立条带，避免遮挡主体。

它不是最终成片字幕。视频 Prompt 必须明确要求输出全屏连续镜头，不保留网格、分隔线和制作注释条。

## 5. 三组案例反推

### 5.1 宠物医院 / 维生素 B：四格

1. 主人突然探身，柯基惊起，门店标牌完成场景和主题建立。
2. 柯基高速旋转成毛发龙卷，完成问题升级。
3. 毛团爆开、人物后仰、柯基尴尬缩身，完成人与狗的双重反应。
4. 发光维生素 B 盾牌成为知识点的实体结论，狗绕牌冲刺形成高潮。

这四格不是“医院四张照片”，而是完整的动作因果链。

### 5.2 眼部 / 体重：四格

1. 放大镜、浑浊眼睛和夸张泪流把眼部问题可视化。
2. 维生素 A 卡片被主人举起，眼部分泌物爆开消失。
3. 柯基高速吞食，食物碎屑和旋转背景表现“吃很多”。
4. 体重秤仍显示极端数值，主人和狗同时震惊，完成反常识结论。

其关键不是写了“维生素”几个字，而是每个知识点都被做成能参与表演的道具。

### 5.3 腿部 / 维生素 D：五格

1. 柯基弯腿摇晃前进，给出身体异常。
2. 主人追赶、狗急滑，动作升级。
3. 维生素 D 骨形图标、骨骼影像和腿部电流把原因可视化。
4. 草、土、墙面进入圆形局部窗，狗在风险源之间冲刺。
5. 主人全宽拦截，狗急刹，巨幅警示牌完成高潮和结论。

第五格存在的理由是需要一个独立的“阻止 + 警示”收束；若强塞进第四格，知识演示和剧情高潮会互相抢画面。

## 6. 生图 Prompt 应采用的结构

故事版智能体对每个文案段输出一段可直接复制的生图 Prompt，顺序固定：

1. **全局规格**：风格、比例、格数、版式、分隔方式、画质。
2. **资产锁定**：具体人物、宠物、服装、毛色、体型、场景和关键道具。
3. **连续性要求**：角色身份、空间方向、道具状态、时间光线保持连续。
4. **Frame 1 至 Frame N**：逐格写静态决定性瞬间和对应的动作注释条。
5. **负面约束**：不重复镜头、不出现多余角色、不改变犬种服装、不把动物人形化、不血腥、不把多格变成一张混乱大场景。

每格建议采用：

`Frame N｜镜头功能：景别/机位；主体位置与动作前势；表情、四肢、耳尾和重心；道具状态；环境反馈；语义包装；本格下方注释条内容。`

## 7. 验收标准

| 检查项 | 通过标准 | 拒绝条件 |
| --- | --- | --- |
| 格数 | 只输出 4 或 5 格，且有语义理由 | 凑格、少格、随字数机械切格 |
| 版式 | 四格 2×2；五格 2×2 + 底部全宽 | 五格上二下三、格子大小混乱 |
| 角色 | 每格均能识别为同一具体人物与宠物 | “同一只狗”式空泛描述、犬种或服装漂移 |
| 故事 | 相邻格形成触发、动作、反应与结果 | 只是同一姿势换角度或无关插图 |
| 动作 | 每格有清楚前势或峰值姿态 | 站立、坐着、看镜头等静态摆拍占多数 |
| 包装 | 来自本段不可见语义，并进入角色互动 | 随机问号、桃心、闪电贴纸堆砌 |
| 知识演示 | 友好、局部、清晰、无不适 | 整体剖体、裸露器官、血腥 |
| 镜头 | 至少两种景别与一次明显机位变化 | 四五格构图完全相同 |
| 注释条 | 格号、运镜、动作一一对应 | 把整段口播塞进画面或遮挡主体 |
| 视频可用性 | 每格都能成为一段动作的起点 | 一格包含多个相互冲突时间点 |

## 8. 对现有提示词的修正结论

现有 `10秒故事板导演智能体提示词-v2.md` 应作废重写，原因如下：

1. 它接收完整文案并再次拆段，但真实智能体接收的是用户已经编号分段的文案；智能体不得改动段落边界。
2. 它把五格规定为“上 2 下 3”或“上 3 下 2”，与真实五格案例不符。
3. 它全面禁止可读文字，但对标故事板保留了独立的 Frame 动作注释条，也会在必要时使用语义标牌。正确做法是区分“制作注释/语义道具”和“最终字幕”。
4. 它把每格视频 Prompt 设想成由平台自动组装；真实流程是智能体输出一整段、按格标注的图生视频 Prompt，用户整体复制到同一卡片的一个视频提示词输入框。
5. 它输出面向程序装卡的 JSON；真实智能体是聊天卡片，输出供用户直接复制的代码块。工作台不需要解析聊天 JSON。
6. 它把参考图生成与自由画布节点体系混在一起；新方向是独立的“智能体卡片 + 分镜工作台”，不继续依赖自由画布节点。

以上结论将直接作为新版故事版智能体提示词的输入、方法、输出与质检规范。
