## 叙事内容主线

先识别语义任务：观察用行为证据，分类/排名/比较用共同维度与可比状态，机制说明用现实证据或明确示意，关系段才组织有据的目标、阻碍、选择与后果；不把信息段强造为误读、遮挡或和解。动作有重量、先后和可见反馈，节奏不固定慢速。原文的肯定、否定、条件和认知主体保留；人的误判不变成宠物真实意图，被否定的动机不先演成事实再放弃。

起草顺序围绕同一个可见变化组织，后一步消费前一步的决定，不让四格、视频、表情与机器字段各自重新设计一段戏：

1. 从原文选出本段最值得看清的变化，给出起态与末态的具体证据，同时保留未被证明的动机、因果或后续结果。已有明确结论的比较、说明段如实呈现，不凭空制造悬念。`semantic_event` 突出这次变化，避免把全部流程串成一句话。
2. 选主峰，再围绕同一主事件写五步。五步有同一个作用对象或观察条件，并沿时间向前；前置观察与他者反应可以形成触发、约束或反馈，不能取代已经声明的主任务。先定短句再组装正文，避免从成稿任意抽词补齐字段。
3. 安排真实空间后冻结每镜摄影句：侧位、高度、朝向、景别、固定或唯一主运动、时间与覆盖格。构图让本镜的判断依据可见，例如空隙边界、可比对象的共同尺度；物件原处、路径与去处在移动前后可追踪，晚揭示仍按事件时序显露，不为列齐物件而提前泄露。
4. 从既定镜头中取四个静态瞬间。同一固定镜头覆盖多格时，完整摄影句逐字复用，英文CAMERA使用同一短译；格间只改变采样时刻的角色、表情或物件状态。需要推近或切镜时，先改共享计划及时间和覆盖关系，再同步图与视频。四格不强套发现、惊讶、微笑、对视。
5. 按具体观察或操作任务补充人宠的差异反应和少量生活小选择，末镜停在已经发生的新状态。变化若影响时长、动作或视线证据，回到同一计划修改，再编译双Prompt和performance。未发生的靠近、饮水或接触保持未发生；原文明示愉快或和解时也不强压成冷淡留白。

这次调整针对真实 A2 与 B 中重复出现的同镜不同机位，以及 B 的主峰声明与五步主任务不一致；方法与证据见 `.codex-evidence/narrative-refinement-20261023/actual-A2-B-director-upgrade-plan.md`。复用的是语义到画面的起草方法，不把两例的物件、宠物或具体动作固定成题材模板。内部20维保留为起草后的回查，不再把它们当20个独立填空；不向用户暴露分析表或自评分。

人物先由全文生活情境与已有文字设计目录选角，用户外貌/衣服备注优先，未指定项只选择一次后冻结；文字目录不被称作参考照片。每段普通模式都含完整人宠身份和衣服，逐格仅补可见识别，不靠上一段上下文。参考模式一次给角色三视图与全部分镜，真实图片生成和确认留在工作台。

有据潜台词落实为动作与注意差异或选择。生活细节说明角色本来做什么、什么动作因本段证据而继续、停住或改道；只用少量能影响表演的细节，不额外制造冲突。表情先有任务：辨认位置、控制距离、确认放稳或继续观察，再按物种选两个互相支持的可见信号。触发后有短暂峰值及回落或保留，不每镜强塞全套，不把眉收再舒展、瞪眼再微笑当默认算法，也不禁止有据的惊讶、微笑或互望。人物只在原文或必要动作需要时出现，无人内容不硬加主人；不人化狗眉或借表情坐实宠物动机。宠物服从实际物种的解剖与行为，明确猫不被默认犬种覆盖；年龄对照仅在原文明示时建立可追溯版本。所有独立参考与双Prompt承接商业3D卡通造型，精细/半写实材质不变成摄影；真实参考表示有来源的实际图片。十风格保留美术指纹，不固定运镜或戏剧节奏。

空间先安排证据、路径、真实遮挡和接触点，摄影再揭示关系。道具有依据、路径与去处；连续段允许共享已有观察和边界构图，不提前演完后段独有结果，也不重启已完成动作。图解/修辞在显著澄清或强调命题时可选，不限不可见机制；明确现实/示意/修辞的事实地位，载体有进入、退出与返回现实的连续状态，不为心理或器官事实背书。

## 工程合同

- 不新增机器字段；复制宿主已解析input，必含既有schema与派生 `director_mode:"cinematic"`。时长标签“10秒版：每段2-3个镜头”规范为JSON数值10，15秒同理；其余八个接收字符串原字保留。原卡展示标签与机器类型不能混淆。
- 固定4格2×2，每格88%剧情与12%三行审片底栏，第一行6–12字中文重点，第二行English SHOT/CAMERA，第三行English ACTION；只印引号内中文，不印前缀或引号。底栏中文不占剧情区短文字配额。
- 保留10/15秒与原十种风格；依当前协议10秒2–3镜、15秒3–4镜。面板数量与实际切镜数量独立。
- 复用 `storyboard_performance.v1` 的四类主峰、动作五步、每个实际角色一条人宠表情记录、同一时间轴、逐字excerpt与end_state。先定义最短完整短句，原字连续嵌入正文和节选；表情peak中途不插项圈、站位等细节，不用语义近似代替逐字锚。
- 普通使用严格v2 storyboard包；参考使用 `storyboard_director_plan.v1` 的planned完整计划，不伪造source、URL、history、确认或verified图片。
- 每条参考资产的 `reference_prompts` 明写 `kind/purpose/prompt`，至少一条kind为turnaround；purpose是对应角色的用途句，`purpose.trim().length >= 4`，不能省略。人物和宠物分别写身份、衣着或毛区配饰的定妆用途，不把工程例存在该字段当成正文可以省略的理由；生产parser的严格门禁保持。
- 可见输出每段先图后视频两个text框，与机器字符串逐字相同。演绎重点只来自semantic_event，主峰/段末只来自同份performance，不输出分析长表。
- 宿主受信system `HOST_NARRATION_TIMING_FACTS_V1` 的parsed数值原样映射，unknown/缺块才作明确模型估算；口播与动作容量独立核查。原文按行首数字加点/顿号识别；有编号段仅去段首编号、整段外层【】与首尾空白，无编号按整篇trim为唯一段并保留外层【】，input中的原文字符串始终原样。
- 出版待审主张与未生成、未观看的媒体验收未知留既有段级 `capability_gaps`；`quality_checks` 只用 `check_id/status/detail` 记录本次可完成的规划自查，不能将 `generation_validation:unknown` 塞入规划检查，也不能改pass冒充已验。安全个案可规划，不因同一出版疑问重复unknown阻断；危险/误导视觉仍fail/unknown，免责声明不能放行，规划pass不等于科学、生成或艺术认证。
- 既有 `environment_groups` 保存真实场景几何与锚点，段 `scene_id/scene_zone` 闭合；普通/参考两例和连续段均使用文字环境prompt、anchor_required:false，不增加环境图资产或首轮数量。scene_lock只描述实际区域、确定光源和可达通路，跨室先声明复合zone或明确剪辑。

影响链为：原始接收输入与用户创作约束 → 独立系统提示词与工程例 → 现有严格解析/工作台导入 → 原始input、资产与performance随项目持久化。此子任务不改UI、CSS、API、鉴权、数据库、计费、模型、端口、构建或配置激活；主线程负责接收卡和运行时集成。

## 验证方法

离线脚本将工程例交给现有生产parser、validator、bridge和execution schema，核对普通/参考、四类主峰、10/15秒、原文逐字、角色覆盖、文本锚定、资产不伪造与保存恢复字段。故意删表情、改excerpt、改原输入或加入未知镜头等反例必须拒绝。真实A的只读本地重放已确认input漏派生模式且抄中文时长标签、图中插字打断宠物peak原句、未生成验收unknown混入规划quality_checks等失败，既有反例保留。B另暴露两个参考条目漏purpose，需用缺人物用途、缺宠物用途、长度不足及两者齐全的正反例检验，不放宽parser，不改写真实回复。中文底栏描写可见画面重点，认知不确定性仍由行为、留白和元信息保留。

同镜摄影句一致与主峰五步同事件分别核验：前者可以检查共享句、机位与景别是否在全部覆盖格和视频相同；后者还需人工理解动作的作用对象和前后证据，字段齐全或逐字锚定不能证明叙事正确。新增创作方法应以不同语义的新真实输出验证，不能用重复关键词、人工工程例或自报pass加艺术分。A、A2、B的原始回复和已有评分保持；工程例只证明合同及预期写法，未生成的图像、视频、声音与渲染质量依旧待验。

人工审阅的内容包括：选择是否有意义、潜台词是否可读、生活状态是否具体、人宠反应是否有差异、空间调度是否清楚、情绪是否被强行解释、同批是否重复温柔凝视、留白是否有信息、画面是否耐看。这些不设关键词数量或自动美学分；后续真实界面提交与生成观看由主线程按用户明确授权完成。

## Ultra审阅后的三项一致性修正

各角色的表情峰值可以分布在相邻格，主峰格只承担主事件和关键回应；`image_excerpt` 取覆盖全部峰值的连续多格原字。这样保留反应先后和后入场，不把所有角色硬挤到同一瞬间。普通与参考工程例将犬的后撤峰值放在第2格，主人的停手反应放在第3格，两格共同构成同一图片节选。

首格建立当时已知初态，后用物件允许真实遮挡、场外携入和摄影机揭示；须有可追溯路径，先交代存在与位置再使用。需要晚揭示的信息不为资产清单而提前泄露。首次定装先适配所选风格的比例与面部表达，再冻结身份和衣着。

伸手工程例首格是手留腰侧、前臂尚未伸出的准备态，中文重点与英文ACTION同样指向准备；视频从同一现态开始，第1镜只伸手一次，第2镜犬后撤、后爪落稳、手停身前空气中，看到犬停住后主人才反应，第3镜收手。主事件是由接近改为保留空隙：五步依次为准备、伸手、遇到犬后撤这一空间约束、手停在间隙之外、收手侧让，犬爪落稳仍是同一事件中的可见证据。人物峰值看向后爪落点并略收下颌，随后看犬肩；犬末态看空出的地砖而仍未靠近，不以双方面面相觑代替新状态。

普通/参考两例可见文字与机器JSON同源更新。第1镜的1.1米中景、第2镜的0.65米低位人宠双主体中景、第3镜的1.1米中全景，分别把完整固定摄影句原字复用到覆盖的第1、2/3、4格及视频/action_beat；各镜在同一侧，不暗换轴线或景别。宠物trigger与drive、人物trigger与contact可以共用原字，正文只演一次；五步在视频节选中按顺序出现。首格倒回已伸手状态、固定镜覆盖格暗换机位、用途缺失等反例应被相应检查发现。
