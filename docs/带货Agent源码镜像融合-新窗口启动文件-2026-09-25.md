目标架构是主站现有 Next.js / Commerce 体系。处理方式按以下优先级：

1. **直接复用**：技能元数据、稳定 ID、素材槽、枚举、字段合同、提示词/模板、无冲突的纯函数和静态配置。

4. **后台补证**：包内没有的服务端细节，通过用户授权可见的正常后台、教程、网络请求和任务记录核对。
