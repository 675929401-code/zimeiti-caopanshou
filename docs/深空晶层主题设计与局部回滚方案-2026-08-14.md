# 深空晶层主题设计与局部回滚方案

日期：2026-08-14

## 1. 目标与边界

- 新增独立深色主题 `lattice`，中文名“深空晶层”，不覆盖经典深色与极光玻璃。
- 主站应用广场、共享导航、侧栏、登录、公告及共享二级页统一视觉层级。
- `/cover` 封面制作页明确排除，继续使用自身局部样式。
- 不改变路由、点击行为、排序、筛选、智能体业务数据与工具接口。
- 所有视觉规则按 `[data-theme="lattice"]` 作用域编写，避免按 `data-mode` 污染其他主题。

## 2. 视觉方法

### 背景

- 基底：接近黑色的中性深空色，而不是整页深蓝或整页紫色。
- 固定背景：细网格、低对比纵深带和顶部微亮分界，滚动时背景固定、内容表面移动。
- 不使用离散光球、散景或大面积单色渐变；青、紫、翠绿只作为小面积状态和边缘强调。

### 表面

- 一级表面：导航、侧栏、模态，透明度较低、边界最清晰。
- 二级表面：页面工具区、分类栏，保留背景可见度并使用中等模糊。
- 三级表面：智能体卡片、列表项，使用薄边框、顶部内高光和双层阴影。
- 圆角上限 8px；按钮与输入保持 6px 至 8px，不用胶囊化大卡片。

### 颜色

- 主交互：冷青色。
- 成功与在线：翠绿色。
- 智能与重点：低饱和紫色。
- 警告与费用：琥珀色。
- 正文与辅助文字采用中性灰白，不以蓝色承担全部层级。

## 3. 导航层级

- 左侧保留品牌与工作区身份，中部为一级导航，右侧放余额、通知、主题和账户。
- 一级导航使用稳定高度和明确活动态；分组之间用短分隔线，不靠不同形状堆叠。
- 分类导航作为第二层，视觉权重低于一级导航；滚动时可保持可见但不遮挡页面内容。
- 移动端收敛到主操作与菜单，次要文字入口进入菜单，禁止横向挤压。

## 4. 智能体卡片比例

- 宽屏目标宽度 288px 至 320px，视觉宽高比约 1.75 至 1.9，避免卡片横向铺满。
- 1920px 内容区优先 5 列，1440px 优先 4 列，1024px 优先 3 列，移动端 1 至 2 列。
- 卡片少时不拉伸到整行；卡片多时保持固定间距与稳定高度。
- 头像、标题、描述和状态分别占固定区域，长文本截断，不推动按钮或状态跳动。

## 5. 技术落地

- 新增 `src/app/theme-lattice.css`，集中存放主题变量和作用域样式。
- `src/lib/themes.ts` 只新增主题注册项，不修改旧主题 ID。
- `src/app/layout.tsx` 只新增一条独立 CSS 导入，并同步首屏主题白名单。
- 应用广场若需支持主题专属列宽，只增加 CSS 自定义属性入口；旧主题继续使用原列数公式。
- 新主题通过路由根类或页面稳定类排除 `.cover-studio-v2`，不写封面页选择器。

## 6. 局部回滚

| 回滚范围 | 操作 | 不受影响内容 |
| --- | --- | --- |
| 整个新主题 | 从主题白名单移除 `lattice` 并删除 `theme-lattice.css` 导入 | 经典深色、极光玻璃及业务功能 |
| 仅导航 | 恢复 `theme-lattice.css` 的导航段 | 卡片、背景、二级页 |
| 仅卡片比例 | 恢复应用广场 CSS 变量入口和卡片段 | 导航、主题色、业务排序 |
| 仅背景 | 恢复主题背景段 | 所有表面和交互状态 |
| 单个二级页 | 从该页主题作用域列表移除稳定根类 | 其他页面 |

实施前把每个将修改的文件复制到 `backups/theme-lattice-20260814/`，生成 SHA-256 清单；回滚按文件或模块执行，不整站覆盖。

## 7. 验收矩阵

- 视口：1920x1080、1440x900、1024x768、390x844。
- 页面：应用广场、工具箱、分镜工作台、帮助中心、登录、公告、至少两个其他二级页；封面页只做“未受影响”对照。
- 状态：空态、加载、长标题、长描述、卡片不足一行、卡片多行、侧栏展开/收起、主题切换。
- 功能：导航跳转、分类筛选、卡片打开、键盘焦点、滚动、移动端菜单。
- 判定：无文本重叠、无横向溢出、无布局跳动、固定背景不影响阅读、主题切换无闪白。

## 8. 第二阶段视觉收口

- 应用广场在 1600px 以上固定为 5 个等分流式列，直接占满原本可容纳 7 张卡片的整行宽度；2048px 实测侧栏展开时每张约 335px，侧栏收起时每张约 391px。卡片高 152px、头像 116px。1440px 保持 4 列，390px 为单列。
- 宽屏头像接近卡片内高，只保留窄边；标题最多显示两行，描述最多显示三行，避免放大头像后文字区失效。
- 卡片组在可用内容区整体居中；不拉伸单张卡片，不改变数据顺序，也不挤压顶部搜索和分类栏。
- 主导航字体收为 13px，图标收为 15px，避免导航大而粗重；分类栏和应用卡片沿用同一组玻璃边框。
- 左侧栏不再使用独立纯黑底色。桌面外壳 `.app-sidebar-frame` 与移动抽屉 `.sidebar-drawer` 使用同源暗青极光、42px 格栅和低强度蓝紫过渡。
- 历史对话保持比应用区更暗，但普通、悬停、选中三种状态均使用青蓝玻璃表面；选中态增加细窄青色内边，保证层次与整体配色同时成立。
- `/tools`、`/storyboard-workbench`、帮助页和媒体历史页共享主题底层；`/cover` 明确排除，不改动封面制作局部主题。
