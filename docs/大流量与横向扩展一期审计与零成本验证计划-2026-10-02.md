# 大流量与横向扩展一期审计与零成本验证计划（2026-10-02）

## 1. 结论与边界

本轮只完成源码、部署模板和数据合同审计。当前可支持的真实边界仍是 **1 个公共 Web 进程 + 2–8 个独立媒体 worker**。多 Web 实例就绪度为 `unavailable`，不能把已有存活探针、PM2 自动重启或数据库队列租约写成横向扩展已经完成。

本轮没有启动或停止端口，没有构建，没有访问付费上游，没有压力测试，没有生产写入，也没有修改 `src/proxy.ts`、Nginx 或 PM2 等共享运行入口。`20261002220000_horizontal_scale_observability` 仅保留为设计编号；没有 SQL 文件，也没有迁移执行。

只读后台端点 `GET /api/admin/horizontal-scale-readiness` 返回固定源码审计合同。它需要 `logs.view` 权限，不读取实时指标、不访问数据库业务表、不产生允许审计写入，且响应为 `private, no-store`。

## 4. 零成本验证阶段

### 阶段 0：静态合同

运行 `scripts/verify-horizontal-scale-readiness.ts`。它只读取源码并核对当前边界：单 Web、worker 数量、持久会话、进程内限流、数据库连接、队列租约、共享心跳缺口、磁盘/CDN/WAF 状态以及本合同/API。它不得发送 HTTP 请求或写数据库。

### 阶段 1：数据库外层事务探针

仅在明确放行的严格本地数据库上执行，整轮包在外层事务中并最终回滚，留下 0 个持久夹具。用隔离租户和假任务验证：

1. 会话发放、撤销、禁用和并发上限在两个模拟调用者之间一致。
2. 同一幂等键的 webhook、队列 claim 和账务替身只产生一个业务影响。
3. claim、续租、租约过期、重新 claim 的拥有者和 revision 均可验证。
4. 普通客户端无法直接读写运维表；所有 RPC 遵守最小授权。

阶段 1 不调用 Web、模型、存储或支付上游。

### 阶段 2：隔离双 Web 候选

在非 5000 的隔离端口启动两个候选，通过专用测试负载均衡器访问；这需要单独协调共享运行状态。本轮不执行。验证认证浏览、登录、聊天 mock、上传票据和 webhook mock，并记录每个候选的请求数、会话结果、限流结果和租户归属。

### 阶段 3：故障注入

仅在隔离候选中终止一个 Web，再终止一个处理假任务的 worker。要求：

- 新请求在约定恢复时间内转移；既有请求结果可解释。
- 租约到期后任务可恢复，但供应商提交替身和账务替身各只记录一次。
- 不发生跨用户、跨租户读取或串号。
- 心跳过期、队列 oldest age、claim 冲突和恢复耗时可观测。

### 阶段 4：边缘沙箱

用沙箱域名核对 CDN Range、CORS、缓存键、私有内容 `no-store`、清缓存和回滚；用无破坏规则核对 WAF 误报和限流一致性。本轮不更改生产域名、Nginx、代理或 DNS。

## 5. 必须采集的证据和中止条件

每一工作负载必须记录实际 RPS、并发、P50/P95/P99、策略拒绝、意外错误和测试时间窗。系统侧必须记录 CPU、内存、事件循环延迟、数据库连接占用/等待、队列 depth/oldest age、worker heartbeat age、lease 冲突/回收、幂等冲突、重复任务数、重复账务影响数和租户归属错误数。

出现以下任一情况立即中止：连接等待持续增长、错误率超过目标、P99 超时、任何跨租户结果、任何重复任务或账务影响、心跳/队列年龄不可观测、测试流量命中真实供应商、测试数据无法保证最终回滚。

## 6. 220000 迁移设计保留

预留名称：`20261002220000_horizontal_scale_observability`。当前 `status=design_only`、`sqlFileCreated=false`、`applied=false`。

后续若经审查需要落库，只允许承载共享 worker heartbeat、规范化队列水位/最老待处理年龄和带新鲜度/覆盖率的容量样本。设计必须同时提供 RLS、客户端撤权、最小 RPC、保留期、清理策略和 rollback。不得在该迁移中顺带切换代理、负载均衡、CDN/WAF 或执行器。

## 7. 完成判定

只有在容量目标获确认、共享限流和连接预算落地、关键指标可见、双 Web/worker 故障演练通过，并证明重复任务数、重复账务影响数和跨租户错误数均为 0 后，才能把多 Web 就绪度从 `unavailable` 提升。当前所有 `partial` 仅表示已有局部基础，不表示完整闭环。
