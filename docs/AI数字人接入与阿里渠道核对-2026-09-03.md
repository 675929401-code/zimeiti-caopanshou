## 用户附件对应的阿里产品

附件指向 avatar/2022-01-30 SDK，即阿里云虚拟数字人开放平台；附件内容是控制台用户名和密码，没有包含 AccessKeyId/AccessKeySecret，也没有完整 RAM 登录身份或业务 AppId/TenantId/CharacterId。未复制附件中的凭据到仓库或报告。

该平台与已经实测的百炼 DashScope VideoRetalk、Wan S2V 是不同产品，不能用控制台密码替代 API Key 或 AccessKey。Avatar 更适合配置固定数字人形象后进行播报或实时互动；不能把平台形象训练当成任意上传视频后立即改口型。

- [x] 官方 API、计费与适用范围已核对。
- [ ] Avatar 平台接入：待补充 RAM 专属登录链接或完整登录账号后，核对该账号已开通的业务配置及 API 访问能力。未调用生成、未购买年度形象定制或套餐、未把 Avatar 标记为可用。现有百炼数字人功能不受影响。

## 官方公开价比较

以下为官方接口公开价，不含账号优惠、免费额度、额外形象定制/训练等费用，亦不等同于主站自行设定的用户售价。按 60 秒折算。

| 产品 | 适合功能 | 公开价 | 当前本地状态 |
|---|---|---:|---|
| 百炼 VideoRetalk | 上传原视频与新配音，替换口型 | 0.08 元/秒，4.8 元/分钟 | 已接入且真实成片通过 |
| 百炼 Wan S2V 480P | 单张人物照片与配音生成视频 | 0.5 元/秒，30 元/分钟 | 已接入且真实成片通过 |
| 百炼 Wan S2V 720P | 单张人物照片与配音生成视频 | 0.9 元/秒，54 元/分钟 | 参数已支持；本轮实测为 480P |
| 附件 Avatar 开放平台 | 固定数字人形象视频合成 | 0.165 元/秒，9.9 元/分钟 | 尚未配置可调用业务 |
| 新版万相数字人应用视频创作 | 配置形象后进行数字人视频创作 | 0.1 元/秒，6 元/分钟 | 与附件 SDK 不同产品，尚未接入 |

Wan 图片检测另计 0.004 元/张。若长期使用固定主播，需要连同形象定制费用评估。新版低价免训练图片形象仅支持实时对话，官方明确不支持播报视频合成或直播，不能把它当作照片视频导出方案。

针对当前需求，视频改口型可直接使用已验证的 VideoRetalk；照片说话可使用 H3 或已验证的 Wan。Wan 官方价偏高，不能笼统说阿里所有数字人模型都便宜。
