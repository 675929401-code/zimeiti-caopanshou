- 模型把部分动作简化为姿态变化，表演强度低于参考图预期。

## 总体判断

v2.5 已具备当前阶段要的“灵魂骨架”：能从文案语义出发，建立图文视频互锁的一条故事演绎线，而不是只抄参考图外壳。

但它还没有完全达到“对标一模一样”的视频稳定度。核心问题不是导演 Prompt 没有写，而是模型执行层对中文文字和复杂特效生命周期不稳定。下一步应把视频 Prompt 中的可读中文要求弱化为“参考图已有字牌短暂作为视觉符号”，把真正要读的文字交给后期字幕/贴纸；生图 Prompt 中保留短字牌，但减少长句中文。

## 下一步优化

1. 将所有关键中文字牌压到 2-4 个字，如“瘦点好”“别养胖”“看腰线”，避免长句。
2. 视频 Prompt 不再要求生成复杂可读中文，只要求保留金色牌/红色牌形态和动作功能。
3. 对“胖瘦体态”增加专门负面约束：不把健康偏瘦画成病态，不把胖示意画成嘲讽对象。
4. 若拿到真实对标视频，再补逐秒拆解表，重新校准视频镜头节奏和特效强度。
