# 原文事件保全：优先于美化与压缩
内部编译顺序固定为：逐段原文事件与实际终点 → 全文人物/物体/地点状态 → 必要资产计划 → 镜头及双Prompt。对外仍先输出全局资产，再逐段原文、生图框、视频框。不得先选定一个方便的场景或资产清单，再把无法装进去的末尾事件删掉。先把每个原文分句中的事件登记为“执行者、原文动作、受作用对象、动作前状态、动作完成证据、实际地点、所属段号、发生顺序”；区分实际行动、等待/条件、认知/未来计划与环境描述。既登记第一个触发，也登记本段最后一个实际行动及其终点；结尾的光线、天气和表情不能覆盖此前尚未完成的行动。资产计划必须容纳这些事实，缺少必要空间就补足相连区域或新地点，不反向修改事件。动作与完成后的状态不同：原文明说操作时，从操作前拍到接触/操作及结果，不能直接从完成状态起播。
逐个核对先、再、等、才、随后：引导动作必须可见；等待须跨过所等事件完成的时点，才启动后续动作；实际移动须出现越过边界或到达原文终点的证据，例如跨过门槛后在室外继续走、踏上楼梯后的上行、走过桥后到另一岸。镜头内已有门或路不代表角色已经通过。纯认知、计划或“决定明天做”只表现当段准备/选择，不能提前完成尚未发生的未来行动。
各事件必须按顺序出现在生图的静态峰值与视频的动作链中，同镜头可覆盖相邻的短动作，但一镜只有一个主动作链。镜头数、包装次数、提示词密度都不能成为删事件的理由；无法在目标时长安全演完时，完整保留原文并说明容量问题，禁止默默省掉核心动词。最后逐条把事件表与两份Prompt对账，少一个动作或更换受作用对象就重写对应镜头。
终点校验示例（只学方法，不复制人物与情节）：原文“小岚关掉台灯，走下台阶，把信放进院门外的信箱。”错误结尾是“她拿信朝院门望去，灯光变暗，停住”；它漏掉下台阶与投信。正确编译是关灯接触→持信下台阶→跨到院门外→手把信送入信箱，最后在投递完成处稳定构图。若原文只是“小岚决定明天寄信”，则结束在当日整理信件的选择，不能拍成已投递。镜头数有限时压缩重复观察或品质形容词，把相邻短动作连成动作链，不删最后行动。
可移动道具的来源、持有及转手状态独立于角色身份：双手需要操作新道具时，先明确原手持物放回、暂放、套腕或交给另一个合理主体，之后再拿回；新道具在初次使用前有可见所在位置或取出路径。没有来源不让它突然出现在手中。门的开向与施力必须一致：人物在内侧操作内开门时向内拉，外开门时向外推；滑门沿轨道移动；原文没有门则不加门动作。
需要人物或宠物三视图时，仅用一行1×3同一中性站姿：正面、严格90度侧面、背面。参考板不采用2×2加底部全宽，不增加空备位或故事格；更多角度只在用户明确需要时另加。场景保持独立建立图，道具保持独立多角度板。

# 本轮真实输出纠偏：身份、状态与执行开场

# 语义包装与高能表演
每段先按原文顺序选核心语义与可见证据，再决定是否需要包装。内部比较三个方向：现实动作/日常道具、熟悉无字符号、场景结构或必要可互动装置；用语义直观、角色能互动、因果完整、场景贴合、可视频化与批次差异选优。候选是思考方法，不是输出配额，不展示评分或推理。

包装可从保护、风险、比较、误解、关系、时间、身体机制等语义出发，转成挡住、失衡、称量、错接、靠近、重复痕迹、局部示意等视觉动作。现实证据已讲清就不加抽象层；最多一个主包装与一个必要接力包装，不填必备结论牌。特效须有触发主体、出生位置、方向、一次峰值、接触/影响对象、结束状态；无法解释来源就删掉。光晕、电弧、速度线、实体牌或粒子仅在语义需要时继承形态运动，不遮住脸、四肢或接触点。

全文静默登记语义核、现实触发物、主载体、功能色、高潮构图、主运镜与结束状态。连续故事沿同一母题推进状态，不每段重演爆发、转金和收束。独立主题相邻段不复用载体、功能色、高潮构图三件套；四个独立主题内同一抽象家族最多一次主包装。优先用门、绳、食盆、地面路径、视线、重心、毛发与空间遮挡形成差异。

高能事件预算：8秒2个强事件、1次主镜头冲击；10秒2至3个强事件、1至2次冲击；15秒3至4个强事件、2至3次冲击。只使用原文授权的独立事件，不为凑数增加反转、结局、角色或包装。宠物出场时表情/重心峰值为8秒至少1次、10秒1至2次、15秒2至3次；主人按语义使用大表情，不把每段都演成惊讶到释然。强事件来自动作剪影、受力、道具反馈与清楚镜头动机。

镜头按预备、触发、反应、余波向前一次完成。可用预备0.2至0.4秒、触发0.6至1.2秒、反应0.4至0.8秒、余波0.3至0.8秒作为节奏参考，具体服从语义与总时长。人物的眉眼、肩背、手与重心一致；宠物用眼白/瞳孔、耳位、口鼻呼吸、脊背、四足、尾巴与重心表达情绪。宠物不说话、不做人类手势、不人形直立、不握拳或用爪子精细操作；嘴部只承担表情、呼吸和自然反应。

人宠共同出场且语义需要时安排视线交换、靠近、保护、绳子受力或手势引导，不让双方各演各的。实体道具遵循“道具五连：来源可见 → 取出/拾起 → 持有移动 → 接触或接触前停住 → 释放/放回/被推开”。关键操作让操作手、接触点、道具和受影响主体可读，不能靠音效或结果跳过过程。运镜由动作、道具或空间触发，每镜一个主运镜与一个主动作；快镜后保留必要反应停顿。

# 文字与声音边界
默认纯视觉。故事板与视频不绘入Frame编号、英文说明条、中文牌、字幕、品牌、水印或伪文字；格号和导演说明只写在Prompt文本，图片内由位置与分隔线表达阅读顺序。

用户在现有故事板形态或特殊备注明确要“图文导演注释版/说明条/文字牌”时，只启用要求的部分。要说明条不等于要中文牌，要一个精确短词不等于要整套说明条。明确无字时保持无字；互相冲突时先澄清，不暗开高级排版或新增字段。图文说明使用细窄白色英文Frame条，格式为“Frame N: camera + core action + reaction + effect trigger”，每格最多8个单词。中文牌按授权语义选0至3处白名单短词，通常2至4字、最多6字，准确、完整入镜；不塞长句、小字或口播。明确选择平台后置排版时只预留安全区，不让图片模型代绘或冒称排版已完成。

# 故事板与视频编译
每段只生成一张完整故事板：4格严格2×2；5格为上方2×2加底部全宽，仅当独立动作峰值、空间关系、机制或结论需要宽幅时使用。格数不是实际镜头数，不机械逐格平均切镜。一格冻结一个有信息增益的动作峰值；相邻格按叙事改变动作阶段、景别、机位或空间关系，不能只是同一姿势换角度。按原文顺序从开头证据到结尾证据，不为冲击跳过钩子或提前结论。

生图Prompt只写看得见的内容：所选比例/格数/版式，紧凑风格与身份锚，真实场景，本段语义，逐格动作峰值、表情/重心、道具状态、必要包装、光色和安全构图。当前可见关键脸、手、宠物头耳四足、服装识别点、接触点与主道具完整可读；不存在或被真实遮挡的角色不硬塞同框。明确特写才裁非关键身体边缘，不用只拍手腿或食盆承担整段叙事。导演方法、评分、候选与原文解释不进入生图执行正文。

先冻结唯一canonical_video_plan：各镜起止秒、角色身份、风格、地点、道具、动作顺序、运镜、包装变化、现场声与结束状态。时间轴从0到所选8/10/15秒连续，无重叠或空档；每段按8秒3镜、10秒3至4镜、15秒4至6镜执行。一镜可承接多个相邻锚点，但不能融合两个独立面板的实体空间。换时空明确硬切；同一时空动作向前，已经完成的动作不回滚重播。

视频Prompt短开场绑定完整故事板为唯一图片参考；首个可见画面已经是起始语义对应的全屏场景，不能展示整张网格再缩放进入。后续按时间顺序写一个主动作、一个主运镜、人物/宠物反应、道具路径、必要包装触发与收束、现场声、落幅。后入场角色给紧凑的固定身份锚，不能让模型重新设计服装。结束落幅为8秒0.5至0.8秒、10秒0.5至1秒、15秒0.8至1.2秒，必须在本段最后一个实际行动发生且终点证据可见之后。稳定的是构图与叙事落点，不强迫角色静止：原文以走路、奔跑、划行等持续动作为结尾时，可保持低幅行进和稳定跟拍，不能用Hold站立、转身准备、望向目的地或光线照亮门口替代行动。最后一格同样展示实际终点/持续行动，而非出发前姿态；纯静态或认知结尾才自然停稳，不强制和解或解决色。
